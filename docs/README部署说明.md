## 本地阅读

双击同目录的 `index.html`，从首页进入完整拆解案或完整系统执行策划案。两册保留目录跳转、全文搜索、图片放大和打印功能。Markdown 是可编辑正文；阅读版 HTML 已内嵌正文图片。

## 部署到网页

1. 将本目录中的**全部文件和子文件夹**上传到静态网站空间的站点目录。当前整理版直接使用本目录；旧同名 ZIP 已列入回收。
2. 让 `index.html` 位于网站入口目录，作为默认首页。保留文件名、中文编码和子目录结构。
3. 通过网站地址打开首页，分别进入两册正文，检查图片和跨册跳转。

这是普通 HTML 静态站点，不需要 Node.js、npm、数据库、后端服务或构建命令。既可放网站根目录，也可放现有网站的子目录；所有站内链接均为相对路径。不要把 ZIP 文件本身作为网页入口。

若托管平台询问构建命令，留空或选择“不构建”；发布目录选择含 `index.html` 的这个目录。服务器应按 UTF-8 提供 HTML。两册 HTML 包含完整正文和内嵌图片，文件较大，首次加载需要等待传输完成。
