一辆车速度很高，却不一定能把对手撞出去。斜擦时，车速大部分沿接触面滑走；正面顶住时，后方有没有退路又会改变结果。《撞击王座》的研究要从这些具体条件开始。车辆、技能、场地和成长都在改变接触之前的准备，或接触之后还能做多少补救。

### 1.3 先固定阅读中的几个词

“耐久”指结构生命，归零可撞毁；“稳定”指受击后保持操控的能力，归零引起失衡；“冲势”指加速资源及分段爆发。“撞飞”在团队赛里是一套专门的法向撞击与空中返场规则，不能与普通击退混用。[R04] [R05] [R10] [R11]

| 名词 | 本册采用的含义 | 易混淆的情况 |
|---|---|---|
| 参考速度 | 车辆对比和驱动计算的参考值 | 硬性速度上限 |
| 接近速度 | 两对象在接触法线上的相对运动 | 两车速度表直接相加 |
| 物理冲量 | 接触求解改变运动的量 | 耐久伤害或伤害数字 |
| 稳定损失 | 影响后续转向和冲势的作战状态 | 直接扣除生命 |
| 收藏目录 | 可检视的全部车辆和外观 | 已拥有或已解锁全部 |
| 本机存档 | 当前设备的本地进度 | 已经同步到账户的资产 |
| 试驾 | 展示或训练中的体验入口 | 正式比赛中永久取得该车 |
| 赛季经验 | 通行证升级所需XP | 生涯等级XP或车辆熟练度 |

## 2 一场比赛怎样连接到整个账号

### 2.1 先选规则，再选车

大厅将主要流程写成“模式 → 地图 → 选车 → 确认”。这个顺序有实际原因：大逃杀只允许普通车开局，经典赛使用8辆混战，团队赛采用5对5，军团则是40对40。先确认规则，才能知道车库中哪些选择对本场成立。[R15]

![大厅：正式入口同时展示当前出战车和主要系统入口。](<撞击王座_实机图_20261014/01_大厅.png>)

| 流程步骤 | 玩家需要知道 | 当前承担的操作 | 选错后的成本 |
|---|---|---|---|
| 模式 | 获胜目标、场次、能力是否受限 | 比赛／训练／挑战栏目与玩法分类 | 用错一套战术目标 |
| 地图 | 哪些地图兼容，哪里可坠落 | 当前模式允许的地图及预览 | 带错机动或防护配置 |
| 选车 | 本场是否允许、自己是否拥有 | 过滤列表与出战确认 | 收藏浏览和比赛权限混淆 |
| 确认 | 模式、阵容、地图和规则是一套 | 开赛信息页统一检查 | 到局内才发现条件不符 |
| 加载 | 物理、地图、车型是否准备完成 | 阻止输入穿透的加载协调 | 尚未落地就开始驾驶 |
| 对局 | 三种状态、周边威胁和目标 | 驾驶、冲势、技能、道具 | 失衡、撞毁或坠落 |
| 结束 | 为什么结束、奖励由谁确认 | 生涯和经济各自结算 | 重复领奖或收益遗漏 |

### 2.2 三种长度的目标

即时目标是让一次进攻成立，例如把对手车侧朝向缺口。单局目标是活到最后，或帮团队赢一个回合。长期目标包括熟悉车辆、取得新车型、主题皮肤与通行证奖励。三个层级可以互相支持，也会争用时间。

| 时间长度 | 典型选择 | 保留的结果 | 需要避免的问题 |
|---|---|---|---|
| 接触前数秒 | 接近角度、油门、刹车、技能时机 | 位置与状态优势 | 只盯速度表，忽略法线和退路 |
| 一轮交锋 | 控制住对手还是先恢复 | 耐久、稳定、冲势、技能冷却 | 连续压制没有喘息窗口 |
| 一局 | 挑目标、抢资源、利用机关 | 胜负、目标任务和奖励 | 活得久却不知道怎样获胜 |
| 一组回合 | 团队补给和出场责任 | 回合比分、重新开局 | 把单次阵亡当整场结束 |
| 一次访问 | 练车、刷任务、领奖和改配 | 生涯与通行证进度 | 入口太多，尚未开车就疲劳 |
| 一个赛季 | 驾驶时长、阶段外观、整车目标 | 永久车辆和皮肤 | 误把高级轨价格当真实货币充值 |

### 2.3 系统如何传递结果

车辆决定质量、占地、主动与被动。地形决定接触和退路。驾驶把这些条件变成运动，碰撞与技能把运动变成状态变化，模式再判定哪些变化算淘汰或胜利。最后，结算写入生涯与经济。[R03] [R04] [R05] [R17]

```wz-diagram
系统总图|选车与构筑>驾驶与接触;地图与机关>驾驶与接触;驾驶与接触>耐久稳定冲势;技能与道具>耐久稳定冲势;耐久稳定冲势>模式判定;模式判定>结算与资产;结算与资产>选车与构筑;训练与复盘>驾驶与接触
```

这里最容易出错的是“同名状态有不同消费者”。稳定归零，普通赛可能触发操控错乱；失衡赛的普通物理碰撞又免伤。通行证取得的皮肤能保存，但没有对应整车时未必可装备。拆系统时要追踪结果被谁读取，才知道规则真的影响了哪个选择。

### 2.5 本版本的系统价值在哪里

最有特色的部分是车辆的运动同时承担驾驶、接触和战术作用。炮击、切割、领域与复活没有单独替代整个撞击体系，而是在改变接近方式、持续接触条件或失败后的机会。场地的空洞、坡面与移动平台则让这些能力有不同用途。

长期系统已经具备车辆、外观、通行证和随机奖励，但新存档的展示与权益说明尚未完全一致。继续增加内容之前，应先让玩家分清自己能看什么、试什么、带什么，以及胜负与奖励究竟来自哪条规则。

## 3 驾驶、接触与三条状态

### 3.1 运动的最终负责人

当前VehiclePhysics使用Rapier作为姿态积分和接触冲量求解者。驾驶和技能提出运动请求，结构伤害与归因由M2处理；车模凹陷、火花和声音由表现系统接收结果。这个分工能避免特效为了显得有力而再次推动或扣血。[R04] [R05]

| 层 | 负责什么 | 不应额外承担什么 |
|---|---|---|
| 驾驶输入 | 油门、刹车、转向、冲势请求 | 直接写判胜或交易奖励 |
| 物理世界 | 车体位置、姿态、接触与支撑 | 根据模型视觉估算生命 |
| 战斗规则 | 伤害、稳定、抵挡、反伤和归因 | 重复积分同一段运动 |
| 模式规则 | 接触是否计伤、返场和淘汰 | 私自补出第二次碰撞奖励 |
| 表现 | 凹陷、火花、音效、镜头和数字 | 按画面重算服务器／本地伤害 |
| HUD | 展示实际状态及可用动作 | 把预测值冒充已经结算 |

### 3.2 接近速度不是车速总和

设接触法线为`n`，两车接触点速度为`vA`、`vB`。可用`u = max(0, (vA-vB)·n)`描述沿法线闭合的运动，法线方向与角色顺序要一起记录。两车平行同速，速度表很高而`u`很小；侧擦也可能有较大的切向速度，却缺少正面压入。[R05]

这解释了一个常见误判：看到高速车没有重创对方，不一定是伤害参数失效。先看接触部位和相对方向，再看质量、护甲与模式免伤，才有依据判断哪一环出了问题。

| 接触场景 | 法向运动 | 常见后果 | 复盘重点 |
|---|---|---|---|
| 相向正面 | 双方都可能贡献接近动量 | 双向损失，双方退让 | 谁的有效动量更高、后方空间 |
| 同向追尾 | 主要由速度差贡献 | 前车受推，追车也可能失速 | 追车相对速度与尾部规则 |
| 静止目标被撞 | 静止车没有主动接近贡献 | 被撞方承受攻击，攻击方承担反应 | 不给静止车虚构同等撞击输出 |
| 高速擦肩 | 速度大部分沿切向 | 旋转、擦碰、少量有效损失 | 接触点与旋转，不只看线速度 |
| 抵住障碍 | 接触对象近似固定 | 位移受限、结构损伤 | 障碍类型、破坏门槛与脱离办法 |
| 坡面接触 | 法线倾斜，有重力分量 | 滑落、离地或侧翻 | 支撑、坡度、抓地和平台运动 |

### 3.3 冲量、动量与结构伤害分别调

经典两体碰撞可以用`J≈(1+e)u/(1/mA+1/mB)`解释质量和弹性怎样影响响应，但当前车体有多个碰撞体、转动惯量、接触点和CCD子步，实际求解比这个近似复杂。公式适合建立直觉，正式数据以当前求解和事件记录为准。

耐久伤害另按有效法向接近动量映射，并受门槛、方向、护甲、技能和模式规则影响。调低耐久伤害不应顺手削弱物理推落；调强切割也不应让远离刃口的车凭视觉光圈掉血。当前源码已将结构损失与物理响应分开处理。[R05] [R06]

| 普通地面摩擦 | 0.12 | 平台接触 | 具体平台可乘修正 |
| 大地图地面摩擦 | 0.02 | 大逃杀／军团 | 避免与驾驶阻力重复强减速 |
| 伤害重接近门槛 | 6m/s | 车辆重击 | 障碍另有破坏条件 |
| 攻击贡献门槛 | 1m/s | 主动接近贡献 | 静止车不会自动变成攻击者 |
| 伤害冷却 | 0.45s | 同车对结构结算 | 仍保留真实接触和推挤 |
| 接触事件窗口 | 0.025s | 多接触面合并 | 同一事件合并后再消耗技能 |
| 切割判定间隔 | 0.1s | 真实刃口持续接触 | 同对象与同来源避免重复计量 |
| 单次稳定损失上限 | 45 | 普通稳定结算 | 专属能力及模式另按覆盖规则 |

### 3.5 多个接触面为何要合成一次撞击

车角可能先碰到对手，然后保险杠和上部装甲在相邻子步继续接触。若每个接触面都消耗一次护盾、触发一次重击、计算一次奖励，同一段撞击会被放大。当前实现以事件窗口汇总冲量和接触贡献，限制重复结算。[R05]

复盘因此要同时保存事件ID、车对、接触位置、接触法线、前后速度和已消耗的能力。只截图一个巨大伤害数字，不能说明它来自一次真实重击还是重复处理。

### 3.6 耐久、稳定、冲势各改变什么

| 状态 | 玩家管理什么 | 降到低值后的问题 | 主要恢复／补救 | 淘汰关系 |
|---|---|---|---|---|
| 耐久 | 可承受的结构攻击 | 再次重击、炮击或切割可能撞毁 | 车辆技能、模式重置或复活 | 归零可直接撞毁 |
| 稳定 | 转向、冲势和受控能力 | 操控错乱、无法顺利加速 | 脱离接触、稳定核心、技能 | 归零不直接爆炸 |
| 冲势 | 爆发时机和分段窗口 | 失去加速，耗尽后需松键恢复 | 松开、补给、专属技能 | 通常间接影响逃生与进攻 |

原始配置稳定上限100，受击恢复延迟1.5秒，基准恢复11／秒；当前车辆、品质、被动及天赋会改变有效上限和恢复。截图中新手平衡车稳定115，已经说明“配置100”与“实际115”属于不同计算阶段。

### 3.7 稳定恢复不是无条件每秒加值

脱离有效碰撞后才进入恢复窗口。玩家在中心安全区喘息，和被敌车持续顶在窄桥上，会得到不同的恢复机会。稳压流派与恢复类配置的价值因此依赖能否脱离，而不只是面板每秒多几几点。

策划判断可从“受击后多久再次能够有效行动”入手。恢复太快，侧撞压制很难留下成果；恢复太慢，玩家可能长期看着车辆滑走。当前配置中2至4秒的控制恢复目标属于设计目标记录，需要对局样本验证。

### 3.8 三段冲势改变了按键策略

常规冲势当前有高、中、低三段。设基础容量为B、额外容量为E，高／中界线为`B×2/3+E`，中／低界线为`B×1/6+E`；E默认50。普通基础容量100时，总量150，两条界线分别约116.67与66.67。进入高段、越过中低界线时可以触发分段运动收益。重置触发资格需要恢复条件，持续按住Shift并非每帧重新获得爆发。[R04]

| 条件 | 当前处理 | 对玩家的意义 |
|---|---|---|
| 开始按住且高段资格有效 | 一次进入爆发 | 选择直线与空间再加速 |
| 消耗跨过高／中界线 | 中段触发一次 | 不能把资源当单一均匀条 |
| 跨过中／低界线 | 低段触发一次 | 留给逃生或最后推进 |
| 资源耗尽仍按住 | 要求松开再重新建立条件 | 无法一直压键获得恢复循环 |
| 暂时受控但仍按住 | 可暂停资源与阶段资格 | 控制结束后检查是否能继续 |
| 松开并恢复到阈值 | 按滞回重新授权 | 减少阈值附近反复触发 |
| 撞飞赛补给规则 | 独立满条8秒，仅Buff补满 | 不套普通13／秒恢复 |

### 3.9 从参数到手感的验证

需要固定车型、构筑、地面、接近方向和输入，分别记录加速距离、刹车距离、首次转向、接触后退量、重新可控时间和坠落原因。速度相同而车长不同，掉头所需空间也不同。只比较最高速度不会得到可靠的车型评价。

| 测试 | 控制条件 | 观察 | 可以决定什么 |
|---|---|---|---|
| 直线起步 | 平地、无技能、同构筑 | 1／3／5秒位移和速度 | 驱动差异是否可感知 |
| 制动 | 同进入速度和朝向 | 停车距离、姿态 | 刹车能否给边缘补救 |
| 单次正撞 | 同接近法线及初始状态 | 速度响应、两侧伤害 | 质量与护甲的实际区别 |
| 侧撞 | 相同接触部位 | 旋转、稳定、可控时间 | 旋刃是否有可执行窗口 |
| 窄桥纠偏 | 同桥宽、进场方向 | 成功率、失误来源 | 操作压力是否超过提示能力 |
| 高速多接触 | 相同车对和连续输入 | 事件数、护盾消耗 | 去重是否正确 |
| 失衡恢复 | 同低稳定状态 | 脱离到重新进攻所用时间 | 恢复数值与控制体验 |

### 3.10 当前最值得先修的显示

能力面板把若干基准倍率显示成“×0.0%”，旁边又使用“最高前进速度”“质量×极速”等词，而车库已经明确参考速度无硬上限。原本为1的倍率应该读成“×1.00”或“加成0%”，两套表达不能混在一个表里。[R03] [R04]

这个问题会让新手误以为车头冲量和结构伤害为零，也会让数值人员误读110km/h为速度封顶。修复显示和命名，应早于继续增加一组新的强化参数。对应执行规则见策划案“字段、单位与数值来源”。

## 4 56辆车怎样形成选择

### 4.1 六种原型与三种品质

当前目录以重锤、旋刃、弹簧、稳压、诱导、平衡六种原型组织，每种普通、稀有各3辆。泰坦层除每类3辆外，重锤多天启坦克，旋刃多骑刃王，共20辆。原型确定基本运动与碰撞倾向，品质增加预算，专属技能再改变具体打法。[R03] [R04]

| 原型 | 值得主动争取的局面 | 要付出的代价 | 对手可怎样处理 |
|---|---|---|---|
| 重锤 | 正面接触、窄路推进、压向缺口 | 大质量、掉头与起步取舍 | 绕侧、拆掉直线接近条件 |
| 旋刃 | 转向、侧撞、持续贴身切割 | 正面硬接和承伤不一定占优 | 拉开、对准防切方向、避免被贴住 |
| 弹簧 | 反击、回弹、边缘补救 | 反弹过量可能把自己送出安全区 | 假撞诱盾、持续压制或换方向 |
| 稳压 | 脱离后复原、保持姿态、持久战 | 爆发与追击需要另找机会 | 集火、追击恢复窗口、限制退路 |
| 诱导 | 假目标、资源争夺、改变追击 | 自身承伤和稳定可能更脆 | 识别真实位置、打断准备、不要追假靶 |
| 平衡 | 学习通用驾驶、多目标切换 | 专项收益较少 | 用自身专长逼其进入不利局面 |

品质预算存在明显差别，不能把普通、稀有、泰坦描述成只换外观。质量、耐久、冲势、占地与专属能力均可能改变局面。若未来采用同条件排位，需另规定如何处理品质和技能差，而非只统一一个速度参数。

### 4.2 一辆车的数据由哪些层组成

当前有效数值来自基础车型、原型、品质、模块、天赋、配件与临时状态，再经过新机制覆盖。旧版`CONFIG.maxSpeed=15`不能直接代表车库显示速度，当前最小巡航参考110km/h且无硬性速度上限。拆分表需要保留各层，否则调整一层时很难知道谁又把它改了回来。[R03] [R04]

| 数据层 | 举例 | 何时生效 | 需要保存的身份 |
|---|---|---|---|
| 车型基础 | 本车质量、长宽与模型绑定 | 选车或进化时 | vehicleId |
| 原型 | 重锤质量倍率、旋刃转向倾向 | 车型所属流派 | archetypeId |
| 品质预算 | 普通／稀有／泰坦基准 | 对应车型层级 | rarity与预算版本 |
| 模块 | 保险杠、底盘、辅助件 | 适用休闲规则 | loadout及模块ID |
| 天赋 | 质量、稳定、冲势恢复 | 规则允许且条件满足 | 已生效节点与条件 |
| 大逃杀配件 | 类型、品质、数量 | 本局取得与安装 | partId、quality、slot |
| 机制覆盖 | 三段冲势、继承、动态最高项 | 当前机制版本 | 参数版本及来源 |
| 临时状态 | 保护、控制、加速或领域 | 状态进入至到期 | owner、来源、剩余时间 |

### 4.3 相同原型下，具体车型仍要有理由

普通车同原型3款，应帮助玩家体验轻重、转向和接触的取舍。稀有车拥有独立主动参数，可作为新的处理工具。泰坦层的切割、领域、炮击、复活和继承则改变更多任务，教学和对抗说明也要随之增加。

车型推荐要写“它在哪种地图、什么模式、哪个条件下有用”。只说某车强，会遮住它的准备时间、冷却、占地、落点和对手反制。例如领域半径大，却需要对手留在里面；坦克能远程攻击，却需要炮管对准和遮挡成立。

### 4.4 当前目录的查看与使用

![车库：目录、出战车、原型、品质和参考数值在同一页面展示。](<撞击王座_实机图_20261014/02_车库与基础数值.png>)

| 动作 | 玩家得到什么 | 是否代表取得整车 | 需要说明 |
|---|---|---|---|
| 浏览目录 | 看到全部车型 | 否 | 总数与拥有数分别显示 |
| 旋转模型 | 观察尺寸、外形和机制 | 否 | 当前展示车型与实际出战车 |
| 查看能力 | 读主动、被动和计算 | 否 | 哪条规则是最终生效值 |
| 比较 | 对比若干车型 | 否 | 相同构筑及天赋条件 |
| 试驾 | 进入练习体验 | 不自动取得 | 是否保存战果或赛季时长 |
| 设置出战 | 修改后续比赛选择 | 需符合权益与模式 | 保存成功与锁定原因 |
| 装备主题皮肤 | 应用于对应整车 | 不授予整车 | 已拥有皮肤但缺车时的处理 |

当前注册表保留“全部开放”的旧式默认说明，但现行经济许可与备战过滤已接线：普通18辆可用，稀有和泰坦需要拥有。新存档收藏仅有`balanced_common_1`，因此普通可用数量也不能直接当成收藏数量。试驾是独立临时入口，退出后不增加永久整车。[R17] [R15]

### 4.5 占地怎样改变撞击游戏

车辆长宽来自实际资产尺寸，碰撞体采用简化车体包络。宽车更容易挡住通路，也可能更难穿过窄桥；长车转身和抵墙时会更早触碰边界。模型高精度只负责显示，规则需要稳定的碰撞尺寸。[R03] [R05]

| 尺寸因素 | 可能的收益 | 可能的成本 | 评估方法 |
|---|---|---|---|
| 较宽 | 抢线、保护队友、接触覆盖 | 窄路通过、避让 | 相同桥宽下的通行与擦碰 |
| 较长 | 接触范围和切割装置布置 | 掉头空间、尾部暴露 | 低速掉头及横向纠偏 |
| 较高 | 视点与设备布置 | 惯量、倾斜和车内遮挡 | 坡面、翻滚、驾驶眼点 |
| 刃口突出 | 真实接触工具 | 有效范围与反切要求 | 刃口命中，而非模型总半径 |
| 装饰突出 | 主题识别 | 遮挡和视觉误导 | 确认它是否实际参与碰撞 |

### 4.6 继承车型的取舍

天启坦克继承泰坦坦克部分基础与装甲，骑刃王继承环刃天枢部分属性与切割；新外观和动画不应默认再加一套未说明的战斗加成。继承关系要记录到表，明确共享什么、替换什么、仍独立什么。[R04] [R07]

王座零式另按全目录若干最高属性的一定比例计算，不复制反伤。这意味着改另一辆车的最高质量或耐久，也可能间接改变王座零式；它的平衡不是只查自己的参数。目录扩展或参数更新后，需要重算这一关系，而不是沿用旧缓存。

### 4.7 车辆丰富度怎样验证

先按任务统计，而非按颜色或数量统计：是否有守住窄路的车、逼迫对手移位的车、能帮助队友脱离的车、适合资源路线的车、能在掉出平台前补救的车。同一车型在两种任务里有合理取舍，就比多一台只有名字变化的车更值得研究。

车辆选择数据应附模式、地图、拥有条件与熟练度。低选率可能来自未拥有，也可能来自教学缺失；不先拆开这两类原因，就容易把获取问题误修成强度问题。

## 5 技能、切割、炮击与持续区域

### 5.1 技能表要拆到动作上

当前能力包括普通原型技能、18款稀有主动、泰坦专属能力、继承能力，以及特殊按键和自动触发。F不是所有能力的唯一入口：坦克与信标涉及R，磁涡涉及地图显示，银脊锚车还有每局死亡触发。[R07] [R08] [R14]

| 能力类型 | 先取得的条件 | 玩家会改变什么 | 对手可以观察什么 |
|---|---|---|---|
| 强化一次接触 | 接近到可命中的方向 | 保留技能直到接触成立 | 预警、蓄势、首击消耗 |
| 保护与反射 | 判断下一次攻击 | 用时间换承伤或反击 | 保护剩余、方向与失效 |
| 位移和机动 | 路线、地面、输入 | 切入、脱离或补救 | 运动方向、落点和冷却 |
| 持续切割 | 真实刃口维持接触 | 跟随目标而非撞完就走 | 刃口位置、接触音和减血 |
| 远程炮击 | 瞄准、无遮挡、资源 | 接触前消耗和逼位 | 炮管、弹道、命中与遮挡 |
| 跟随领域 | 保持自己与目标的相对位置 | 围住目标或护住队友 | 圈边、范围与移动 |
| 固定领域 | 选施放点并留住对象 | 限路、诱导或拆补给点 | 圈边、预热、停留门槛 |
| 自动复活 | 本局资格尚未消耗 | 首次阵亡后重新参与 | 复活点、保护与已用标记 |

### 5.2 一个技能需要多少字段

`duration`和`cooldown`只是开头。还需知道施放时点、预热、对谁生效、作用形状、是否跟车、如何与队友交互、何时中断，以及跨回合是否清除。字段完整，界面和AI才能使用同一套判断。

| 字段 | 当前分析时追查的问题 | 典型风险 |
|---|---|---|
| ownerVehicleId | 谁具备能力 | 进化后仍保留旧技能 |
| activation | F／R／Tab／自动 | 指引让玩家按错键 |
| resource | 冲势、稳定或无即时消耗 | 免费连续施放的误解 |
| warmup | 预警何时开始，能否中断 | 对手尚未看见就被命中 |
| shape | 刃口、射线、球体或地面圈 | 模型视觉被当伤害范围 |
| targetFilter | 敌人、队友、自己、障碍 | 误伤或重复增益 |
| tick | 连续效果怎样累计 | 显示帧率改变总伤害 |
| stacking | 同类叠加、独立来源或取最大 | 无限覆盖恢复与防护 |
| cancel | 淘汰、换车、退出、回合结束 | 幽灵领域继续伤害 |
| attribution | 功劳归施放者还是接触者 | 助攻和淘汰争议 |

### 5.3 切割要求刃口真实接触

旋刃的持续价值来自在空间中保持接触。当前系统区分模型动态部件、刃口接触和伤害判定，切割按时间间隔累计耐久与稳定损失。只有视觉高速旋转，目标没有接触刃口，不能因此承受持续伤害。[R04] [R07]

对手可以改变车头朝向、拉开、利用墙体阻挡或用防切能力处理。双月割轮的正面防切与其他面减免，则让“同样贴住”变成不同结果。切割分类应同时写接触条件和反制，不能只给一个每秒伤害。

### 5.4 炮击受瞄准和遮挡限制

坦克的炮击与索敌涉及炮管实际方向、视线遮挡、冷却及稳定消耗。跟踪标记已经找到目标，不代表炮管已到位；目标在地形后方，也不能透地形命中。玩家需要分清选中、对准、开火和命中四个状态。[R04] [R07] [R14]

| 状态 | 显示应告诉玩家 | 不成立时的表现 |
|---|---|---|
| 发现敌车 | 可锁对象与敌我身份 | 没有目标或对象不可用 |
| 正在追瞄 | 炮管转动和角度误差 | 延后发射，继续驾驶 |
| 可开火 | 冷却和稳定满足 | 资源／冷却限制提示 |
| 遮挡 | 地形或车辆阻断弹道 | 标明阻挡，不穿透发奖 |
| 发射 | 真实弹道与来源 | 发射与伤害结算分别记录 |
| 命中 | 结构、稳定和推移结果 | 未命中仍消耗适用资源 |

### 5.5 三种大圈不能只按半径归一类

地脉镇车使用跟随自身的领域，风暴信标将风暴留在施放点，磁涡指挥车在固定点预热后施加方向控制。当前三者参数中的半径均为48m，却要求不同的移动和对抗：跟随圈需要贴近，固定圈需要选址，停留门槛又要求留住对象。[R07]

| 车型 | 空间关系 | 关键时点 | 玩家主要决定 | 对手主要选择 |
|---|---|---|---|---|
| 地脉镇车 | 领域跟车 | 持续期间的接近 | 要追谁、走哪条线 | 脱离作用范围或反打 |
| 风暴信标 | 固定风暴圈 | 连续停留3秒后瘫痪9秒 | 在哪施放、怎样逼停留 | 尽快出圈，防止被堵路 |
| 磁涡指挥车 | 固定混乱圈 | 预热后转向控制 | 放在通路还是资源点 | 提前绕开、保留驾驶补救 |

半径相同仍要分别评估地图宽度、缺口位置、团队人数和同类叠加。大圈在经典窄平台上可能覆盖重要通路，在1920m大逃杀中则只是一个局部障碍。

### 5.6 防护不是免疫场地淘汰

八方稳定堡的无敌和恢复，保留实体碰撞；车仍可能被推出平台。双月割轮防切也不等于免疫炮击或坠落。独立伤害分类能让防护有清楚用途，同时保留位置对抗。

| 威胁来源 | 必须分别检查 | 不能默认合并 |
|---|---|---|
| 普通冲击 | 方向、护甲、冲势、模式 | 切割防护 |
| 切割 | 刃口、接触时长、防切方向 | 所有攻击减免 |
| 炮击 | 弹道、命中、专属系数 | 普通碰撞冷却 |
| 持续领域 | 进入、停留、tick、队伍 | 物理车对碰撞 |
| 反伤 | 原伤、反射深度、来源 | 反复反射直到无穷 |
| 坠落 | 支撑、离地高度、模式资格 | 有耐久就不会淘汰 |

### 5.7 复活重新分配一局风险

银脊锚车每局死亡后有一次自动复活。这会让首轮高风险进攻的代价低于没有复活的车，但安全复活点、生命比例和保护时间仍决定它能否重新行动。回合重开与整场重开必须区分，不能无意多发复活资格。[R07]

评估时记录首次阵亡原因、复活位置、保护期间造成的影响，以及再次死亡。只看最终存活率无法说明优势来自本车基础还是额外生命。

### 5.8 同时控制多个能力的注意力成本

F主动、R索敌或激光、Shift冲势、E道具、X锁定和Q视角，会在交锋中争用手指和注意力。不是每个能力都需要再加一个按钮；有些状态可自动维持，有些必须让玩家承担明确的选择。

学习顺序可从驾驶、接触、冲势开始，再加入主动和道具，最后加入特殊车型操作。界面应显示当前车真正具备的动作，避免把所有按钮放出来却没有效果。

### 5.9 旧说明与现行获取发生冲突

机制说明中仍能找到骑刃王的早期通行证定位；当前永久特别池却将骑刃王作为1.5%与60抽保底的唯一主奖，通行证100级奖励为免费泰坦坦克、高级天启坦克。内容获取以现行经济规则为准，旧技能说明需要更新。[R07] [R18] [R19]

这类冲突会直接影响玩家目标和投入，不能只改成“以实际为准”。对应章节应明确车型、获取路径、重复补偿和时间限制，并让车库、奖励预览和任务提示引用同一个表。

## 6 工坊、天赋与外观的分工

### 6.1 三槽构筑为何需要代价

车头、底盘、辅助三槽分别影响接触、驾驶与资源利用。当前每槽包含基准件和两个取舍件，重置免费。玩家可以围绕同一车型试几套配置，不必因改错一次就付费回到起点。[R03]

![工坊：模块同时列收益与代价，数值计算可与车库核对。](<撞击王座_实机图_20261014/04_工坊构筑.png>)

| 槽位 | 模块 | 当前收益 | 当前代价 | 适合验证的任务 |
|---|---|---|---|---|
| 车头 | 基准车头 | 无额外修改 | 无 | 建立对照 |
| 车头 | 加重保险杠 | 车头冲量+12% | 转向-8% | 正面推进是否值得放弃绕侧 |
| 车头 | 破风板 | 转向+6%、侧击+8% | 车头冲量-6% | 侧撞能否弥补正面损失 |
| 底盘 | 基准底盘 | 无额外修改 | 无 | 基线操控 |
| 底盘 | 回弹底盘 | 受击反弹+15% | 稳定恢复-15% | 边缘反击与长交锋恢复 |
| 底盘 | 陀螺仪底盘 | 转向+10% | 速度参数-5% | 在无硬上限驱动下实际影响 |
| 辅助 | 基准辅助 | 无额外修改 | 无 | 基线资源管理 |
| 辅助 | 快充线圈 | 冲势恢复+15% | 爆发防护-10% | 多轮爆发和被反撞风险 |
| 辅助 | 磁吸弹药架 | 道具持续+20% | 冲势恢复-10% | 控制时长与机动资源取舍 |

### 6.2 倍率顺序会影响最终结果

多个百分比可能乘算，也可能按基准加算。当前结果表保留base、prototype、modules、talents等来源；新增机制还把旧速度代价映射到驱动效率。配置表写“速度-5%”时，需要说明它影响哪个阶段，防止界面数字没变化却让玩家以为模块无效。

相同车做对照时，除了模块，还要记录天赋、品质、当前模式和配件。把一辆有全部天赋的车与初始车直接比较，得不到纯模块收益。

### 6.3 四条天赋分支

当前节点为A、B、C、D四支，每支6个节点，另有root。A围绕接触与质量，B围绕稳定及防护，C围绕操控和地形，D围绕冲势与道具。条件节点需要在满足触发条件时解释收益，不能一并塞进常驻面板。[R24]

| 分支 | 核心选择 | 典型条件节点 | 需要观察 |
|---|---|---|---|
| A 动量与接触 | 正面、侧面、反推和质量 | 冲势期间质量增加 | 同接触方向的响应 |
| B 稳定与防护 | 上限、恢复、减损 | 低于10稳定的临界支撑 | 保护触发和重置 |
| C 操控与场地 | 转向、倒车、边缘和离地 | 0.6R外回正、离地控制 | 独立于自动驾驶的补救 |
| D 能量与工具 | 恢复、消耗、道具和反击 | 抵挡重击返还冲势 | 来源去重与资源上限 |

当前运行环境还存在便于体验的全节点开放处理，不能按早期root初始值推断玩家自然成长速度。节点结构保留，但点数、解锁节奏和正式获取规则需要统一到发行方案。

### 6.4 外观应保留战斗身份

188套主题皮肤绑定具体车辆。外观可以改变颜色、材质、装饰或主题表达，碰撞尺寸、耐久和技能判定仍由车辆定义负责。某些老涂装还写有“轻量尺寸”等词，容易让读者以为皮肤改变实际占地；正式说明要和现行实现核对。

![主题皮肤：取得、预览与装备需要分别处理。](<撞击王座_实机图_20261014/07_主题皮肤与车型关联.png>)

| 外观变化 | 可带来的价值 | 必须保留的战斗信息 |
|---|---|---|
| 配色主题 | 收藏、审美、季节记忆 | 敌我标识和技能状态 |
| 金属与冰火材质 | 车辆个性 | 刃口、炮管和护甲方向 |
| 装饰部件 | 识别与展示 | 真实碰撞包络 |
| 灯光和尾焰 | 运动反馈与主题 | 冲势／控制反馈不能被淹没 |
| 高精度近景 | 车库观赏 | 对局远景仍能认车型 |

### 6.5 解锁、拥有和装备是三件事

抽到皮肤可能先于整车。当前经济系统允许保存这种外观，但装备需要对应车型可用；奖励不会自动改出战车和当前涂装。这样能减少“开奖以后配置突然变了”的困扰，也要求缺車提示给出清楚下一步。[R17] [R18] [R19]

继续制作时应追踪“预览 → 取得 → 适用 → 装备 → 使用”，不能把领奖人数直接当成外观使用人数。对暂缺整车的玩家，记录取得状态和获取路径即可，不必再送一个误导性的立即装备按钮。

## 7 场地把撞击变成路线问题

### 7.1 同一次碰撞，退路不同，结果就不同

车与车的接触发生在地形里。中心平地可以让玩家退后恢复，窄桥把修正空间压缩，外圈可能只剩一次刹车。地图改变的是“怎样接近、怎样脱离、失败后还有没有补救”，不仅是地板颜色。[R01] [R05] [R24]

| 空间条件 | 影响的决定 | 对撞击结果的影响 | 要给玩家看的信息 |
|---|---|---|---|
| 外边缘 | 继续追还是回中心 | 小幅位移也能淘汰 | 缺口、距离、方向 |
| 窄桥 | 谁先占线、是否让路 | 宽车与横向修正受限 | 真实桥宽与连接 |
| 环形通路 | 顺行追击还是切内线 | 对手可能绕过正面威胁 | 通路内外边缘 |
| 障碍掩体 | 借遮挡躲炮还是抢视线 | 减少远程威胁、限制转身 | 可破坏与不可破坏区别 |
| 低摩擦面 | 提前刹车、保留抓地 | 同样输入更易滑向危险 | 材质与减速反馈 |
| 坡面 | 选行驶方向、留冲势 | 重力与支撑改变接触 | 坡向、可落脚区域 |
| 移动平台 | 何时进入、是否跨越 | 相对速度不只来自车辆 | 平台运动方向与周期 |
| 塌陷区域 | 抢资源还是撤离 | 旧安全路线可能消失 | 清楚预警和失效顺序 |

### 7.2 当前八张经典地图

| 地图 | 主要结构／材料线索 | 当前机关说明 | 适合研究的打法 | 易发生的误读 |
|---|---|---|---|---|
| 云端大厦顶部 | 多屋顶平台与窄桥 | 间歇横向强风 | 抢桥头、顺风推落、逆风回正 | 把全部屋顶当一整片地面 |
| 巨石圆柱 | 圆柱、双层环台和斜坡 | 局部旋转平台改变车流 | 抢内线、台阶衔接、分层追击 | 只看俯视位置而漏掉高度 |
| 蜂巢塌陷区 | 六边形地块 | 地块闪烁后下沉 | 逼离安全块、抢撤退路径 | 预警块仍有支撑但将失效 |
| 远古遗迹祭坛 | 巨型石台和可撞石柱 | 沙尘干扰边缘提示 | 破坏掩体、正面争路 | 看不清就误认没有边缘 |
| 热带雨林树冠 | 巨型叶片平台、湿滑表面 | 叶片摆动与果实掉落 | 小范围修正、预留刹车 | 把视觉叶片当固定平面 |
| 冰川雪地 | 浮冰与冰桥、低摩擦 | 冰桥受撞击开裂 | 用惯性追击、控制回弹 | 平地驾驶习惯导致刹不住 |
| 熔铁铸造厂 | 工业平台、可撞护栏 | 喷气与铁水喷发 | 推向危险窗、破护栏 | 把护栏视为永久保险 |
| 凌空机械港 | 空中码头与移动栈桥 | 机械臂扫过平台 | 掐平台时机、错位进入 | 平台移动引起的位移被归为车辆漂移 |

表中为当前目录和机关说明，精确面积、桥宽与可行驶区域需要地图参数导出。文本中出现的摩擦或转向修正，仍应与实际材料和运行参数核对，避免把旧卡片描述当全部物理事实。

### 7.3 机关必须有完整状态

一台机械臂可以存在于画面，但只有预警、触发、实际作用、结束和恢复都能衔接，才形成可学习的机关。玩家看到预警后能够撤离，也可以把敌人逼进危险区，这时机关才增加选择。

```wz-diagram
机关状态|等待>预警;预警>激活;激活>冷却;冷却>等待;预警>玩家调整路线;激活>接触与模式结算
```

| 阶段 | 玩家需要知道 | 系统记录 | 失败情形 |
|---|---|---|---|
| 等待 | 什么对象可能启动 | 时钟、目标与条件 | 对象看着可用却没有规则 |
| 预警 | 哪里将危险、还剩多久 | warningStart、区域 | 提示晚于真实作用 |
| 激活 | 当前范围和作用 | activation、碰撞或效果 | 视觉范围与判定不符 |
| 冷却 | 下一次何时可利用 | remaining、恢复条件 | 玩家把余效当永久效果 |
| 清除 | 模式切换后彻底退出 | 会话ID、对象引用 | 旧机关作用到新地图 |

### 7.4 可破坏障碍也是战术资源

障碍提供遮挡、阻挡与接触对象，破坏后则改变后续通路。冲击破坏和切割破坏需要各自条件；装饰外形破裂不应凭表现代码顺便扣一次车体血。当前物理对破坏障碍保留独立接近门槛。[R05] [R06]

| 障碍用途 | 对局中的选择 | 数据需要说明 |
|---|---|---|
| 掩体 | 避炮、阻止追击 | 可遮挡对象、耐久与破坏方法 |
| 护栏 | 防止意外滑落 | 何时被破坏、是否留缺口 |
| 大型固定物 | 控制通道、承受接触 | 固定／可动、可碰撞形状 |
| 掉落物容器 | 冒险破坏换资源 | 内容、归属与重复触发 |
| 残骸 | 剩余阻挡或纯表现 | 存活时长及是否影响路线 |

### 7.5 跨越、悬空与落地

坡面和空洞需要检查车体实际支撑，不能只在车辆中心点查询一次地面。宽车横跨小缺口时，中心在空洞上而两侧仍有支撑；斜盘上，世界坐标下的圆形距离也未必等于盘面上的距离。[R05] [R12]

落地要处理姿态、速度和接触，不应瞬间回到默认车高。撞飞赛另有返场资格，普通坠落则使用各模式淘汰条件。地图分析应按地面、离地、悬挂、飞行与淘汰分别记录。

### 7.6 大地图需要局部目标

大逃杀采用1920×1920m的进化荒原，军团使用草原、沙漠、雪原的大范围高度场。长距离行驶提高了路线与资源的重要性，也增加发现敌人、判断支撑和获得及时反馈的要求。[R09]

如果玩家长时间只按前进，没有资源取舍、路线风险或敌方信息，地图面积不会自动变成策略深度。评估应记录首次有用拾取、首次威胁、第一次进化及中后期汇聚位置，而非只报告地图尺寸。

### 7.7 外部地图包与正式模式分开看

项目中还存在环道接力等独立交付。正式模式入口当前读取8张经典地图、进化荒原、训练圆盘、团队圆盘与军团地形。未出现在本次正式入口中的内容，本册只作为后续扩展候选，不宣称它已经成为大厅可选择地图。

## 8 经典赛、挑战和训练各承担什么

### 8.1 经典竞技的首要问题

经典赛为8辆个人混战，淘汰可以来自坠落或撞毁，最后存活者获胜。设计目标中推落与撞毁的比例记录为80%／20%，这是当前策划倾向，尚未得到本轮多场样本证明。[R15] [R24]

![经典竞技：位置、资源状态与场地威胁在同一战场中处理。](<撞击王座_实机图_20261014/20_经典竞技实战.png>)

| 阶段 | 玩家主要任务 | 策略机会 | 可观察的失败 |
|---|---|---|---|
| 出生 | 找支撑、认边缘、确认车辆 | 安全起步、选首个目标 | 初始重叠或掉落 |
| 首轮交锋 | 试方向与能力 | 切侧、反击、抢道具 | 不理解失衡原因 |
| 中段 | 在恢复与追击之间取舍 | 利用机关、打断恢复 | 连续追击到危险区 |
| 少数幸存 | 管理冷却和剩余耐久 | 逼迫补给、诱导失误 | 过早耗尽逃生工具 |
| 最终结果 | 识别淘汰来源 | 用复盘决定下一次练习 | 只给名次，没有原因 |

### 8.2 混战不等于每个人公平排队

多人同时接触会产生夹击、收尾和第三方收益。玩家需要读到谁在攻击自己，攻击者也需要知道功劳是否来自最后一击、推落窗口还是持续伤害。公平评估不能只做两车互撞，必须包含多人争夺。

当前推落归因存在时间窗口，结构伤害也有近期来源。实现时要避免友军物理接触被误记成攻击，以及同一领域多次tick把一次淘汰重复领奖。

### 8.3 灾变挑战改变哪条基础规则

灾变挑战公开两个变体，并结算挑战徽记。它适合检验玩家是否会根据规则变化重新选路线与资源，而非沿用一套稳定刷法。每次变体需要同时给收益、威胁和结算条件。[R15]

| 比较项目 | 普通经典 | 灾变／地图挑战 |
|---|---|---|
| 主目标 | 最后存活 | 生存之外还有变体和目标 |
| 选图 | 兼容经典目录 | 目标和机关更相关 |
| 信息 | 常规技能与场地 | 公开本局改变的条件 |
| 奖励 | 生涯／对局结算 | 挑战徽记或目标进度 |
| 复盘 | 接触和路线 | 区分操作失败与变体判断 |

### 8.4 六个试炼是原型教学入口

重锤试炼要求8次有效撞击，旋刃4次侧面破势，弹簧在稳定低于30时完成一次反击，稳压存活120秒，诱导使用3次道具，平衡取得一次胜利。固定地图与指定数值原型，可以把练习问题收敛到一个主题。[R24]

但当前试炼保留出战模型和技能，指定的是数值原型。用一辆有大型专属领域的泰坦去做基础侧撞任务，可能绕过教程原本想教的动作。教学验收需决定允许自由体验，还是保证同一套入门条件。

### 8.5 两章十局的作用

“冠军章回·云端启程”和“冠军章回·机关深处”各5关，将胜利、有效撞击、侧击、存活、机关、道具及边缘淘汰串起来。不同关卡要教哪一种概念，可以直接从目标读出；章回故事则负责给这些练习提供连续背景。[R24]

| 关卡类型 | 应学会的判断 | 过关之外需观察 |
|---|---|---|
| 有效撞击 | 建立法向接近 | 是否只是反复擦碰刷计数 |
| 侧面破势 | 看朝向并切入 | 能否在不同阵位重复完成 |
| 低稳定反击 | 留补救工具 | 是否理解低稳定状态 |
| 存活 | 控制风险和回中心 | 是否只躲在AI不追的位置 |
| 机关利用 | 看预警与窗口 | 是否能主动安排接触位置 |
| 完整胜利 | 综合驾驶和工具 | 是否稳定而非一次偶然成功 |

### 8.6 技能训练场提供可控对象

训练场使用半径300m圆盘，当前有普通、稀有、泰坦、装甲、防切等靶车配置。靶车不主动驾驶，可被推动和攻击；恢复、重置、冻结恢复及测试面板帮助复核能力。[R16]

![训练场：实际靶车和原有诊断功能。](<撞击王座_实机图_20261014/18_技能训练场.png>)

| 靶车 | 对应问题 | 建议对照 |
|---|---|---|
| 普通 | 基本伤害与击退 | 同速度正撞、侧撞和静止被撞 |
| 稀有 | 品质与主动工具 | 同原型、相同接近条件 |
| 泰坦 | 大占地与高预算 | 同角度，不混入额外天赋 |
| 装甲 | 方向防护 | 正面／侧面／背面 |
| 防切 | 切割条件 | 刃口位置与防切方向 |

训练状态不直接生成正常对局奖券，但现行通行证有效游玩计时可以覆盖主动训练。把“练习不发胜利奖励”写成“练习不计任何进度”，同样不准确。

### 8.7 练习反馈需要给下一次动作

受到伤害多少是结果，距离、朝向、刃口和炮管对准则解释过程。训练面板可以按接触类型保留短历史，让玩家比较两次实验，而非一直累积一个无法归因的总伤害。

当前历史预算200条、状态显示约10Hz、DPS窗口3秒，这些参数属于反馈刷新和记录预算，不等于物理步频或技能每秒伤害。文档与界面都要把单位写在数值旁边。

## 9 大逃杀：先选路线，再选成长

### 9.1 当前规则的区别

大逃杀从48辆普通车开始，支持单人、双人、四人组队。地图没有传统缩圈，主要威胁为空洞、边缘资源、对手和进化差距。普通车可以沿本局配件路线成长到稀有、泰坦。[R09] [R15]

![大逃杀：资源、配件与进化目标共同影响路线。](<撞击王座_实机图_20261014/23_大逃杀资源与进化.png>)

| 项目 | 当前规则 | 对玩法的影响 |
|---|---|---|
| 场地 | 1920×1920m | 搜索与接近成本更高 |
| 开局车辆 | 48辆普通车 | 初始阶段相对接近 |
| 队伍 | 1／2／4人 | 分工与存活判定变化 |
| 空洞 | 3至6个，半径90至180m | 资源路线必须检查支撑 |
| 配件总量配置 | 480 | 供给需与车辆数及地图分布一起看 |
| 边缘／表面／高风险分布 | 72%／20%／8% | 把高收益与地形风险连接 |
| 进化稀有 | 绿×4或蓝×3 | 路线与库存取舍 |
| 进化泰坦 | 紫×3或金×2 | 高级资源争夺 |
| 缩圈 | 无传统缩圈 | 中后期聚集需由其他目标提供 |

### 9.2 边缘资源为什么有价值

资源集中在空洞边缘，会让玩家不断选择“再靠近一点”还是“先保留安全距离”。撞击也由此带来更高收益：敌人正在拾取时，位置可能已经危险。资源摆放本身就在提供接触机会。

但资源图标、地面支撑和拾取距离必须清楚。若看到的物品在安全地面、实际判定却在空洞外侧，玩家会把路线失误归咎于系统。生成与漂移动画要以可达位置为准。

### 9.3 进化是一次配置变化

进化改变本局车辆模型、属性、主动与被动，旧车的临时状态和物理体需要正确换绑。它不应覆盖永久车库的出战选择，也不应将旧技能冷却或刃口对象遗留到新车型。[R09] [R15]

| 进化前检查 | 进化时处理 | 进化后确认 |
|---|---|---|
| 配件数量和品质满足 | 消耗适用配件并登记结果 | 数量无负值、结果唯一 |
| 当前车仍存活 | 保留规则允许的运动状态 | 不额外出生一台车 |
| 车型映射可用 | 切换模型与能力 | 新ID、品质与技能一致 |
| 接触世界准备好 | 重新绑定尺寸与质量 | 不穿地、不与自己重叠 |
| 本局状态已分离 | 清除旧临时对象 | 永久出战车没有被篡改 |

### 9.4 没有缩圈的中后期问题

早期资源密度与进化目标足以支持探索，剩余人数下降后，玩家可能离得越来越远。当前AI有资源和交战意图，不代表真人也会主动汇合。要采集剩余人数、最近敌人距离、持续无交锋时长和资源消耗，才能判断终局是否拖长。

策划案提出的中后期汇聚措施应先作为试验，例如公开资源批次或可争夺目标；不能为了让对局结束，悄悄加入与“无缩圈”承诺相冲突的致死范围。

### 9.5 组队时，物理接触与伤害分开

队友可以发生实体接触，以保留队形和推挤的真实关系；是否计伤、是否归为攻击、是否触发切割和奖励则要按队伍规则过滤。把友军完全变成可穿透对象，会改变协作的空间成本；把所有实体接触都记成攻击，又会制造误伤和错误功劳。

### 9.6 本局配件与永久收藏的关系

大逃杀进化给每局一个从弱到强的过程，永久车辆与外观给账号长期目标。两者要分别记录：对局内取得的配件不应自动变成永久车权，退出时也不能丢掉已经确认的赛季奖励。

## 10 两个5对5模式为何要单独立规则

### 10.1 共同的回合结构

撞飞赛和失衡赛均为两队各5辆，先赢3个回合获胜，常规为最多5个有胜负的回合。双方同时团灭时重赛，不能把平局误算为某队胜利。两者复用训练圆盘场地能力，但接触、补给和驾驶条件不同。[R10] [R11] [R12]

| 项目 | 撞飞赛 | 失衡赛 |
|---|---|---|
| 主要威胁 | 有效高速撞击后的离地 | 随机陡倾和滑落 |
| 普通碰撞 | 保留推挤，专门处理撞飞 | 物理接触免伤，保留滑移 |
| 圆盘护栏 | 有护栏与专门开口／返场处理 | 无护栏 |
| 冲势 | 800km/h，极速窗口1200km/h | 持续冲势与抓地用于抗滑 |
| 补给 | 极速8、反弹2 | 技能8、粘连2 |
| 额外权限 | 特定补给改变速度／反击 | 先取得技能权限再用主动 |
| 180秒 | 收缩到决战区域，继续交战 | 收缩到决战区域，继续交战 |
| 淘汰后 | 可进入适用观战／队友接管 | 可进入适用观战／队友接管 |

### 10.2 撞飞依据有效法向速度

当前冲势800km/h，极速Buff窗口1200km/h，满条可用8秒且只能由适用Buff补满。撞飞门槛300km/h分别看双方自己的有效攻击法向速度，再比较质量乘该速度得到的动量；比较保留1%容差。两车各150km/h相向不会因为合计300就触发，双方均达高速且动量接近时则可以同时受击。单纯高速同向跟跑与侧擦不能只凭表速触发飞行。[R11]

![撞飞赛：团队、回合、补给和模式专用状态。](<撞击王座_实机图_20261014/21_撞飞赛团队HUD.png>)

追击者需要留直线和补给，防守者可以改变朝向、诱导擦碰或争取返场。技能、天赋和碰撞返能如果能绕过“仅Buff补满”，就会破坏补给争夺的意义，当前系统已对资源授予路径增加限制。

### 10.3 飞出圆盘后还有一段操作

被撞飞进入空中状态后，朝向、推力、刹车和落点判断决定能否返场。返场不是把车瞬移回盘心，也不是只给一段镜头动画。世界支撑、落地姿态和重新获得接地必须连续处理。[R11]

| 空中阶段 | 玩家动作 | 必须检查 |
|---|---|---|
| 离地 | 辨认盘面和飞行方向 | 镜头仍可看清落点 |
| 调整 | 朝向、推力、刹车 | 飞行输入作用于正确车辆 |
| 接近 | 减速并对准可落区域 | 缩盘后的可落范围 |
| 落地 | 恢复接地与驾驶 | 不与护栏或场地下层卡住 |
| 失败 | 进入淘汰与观战 | 不残留飞行控制或旧目标 |

### 10.4 失衡赛的随机倾斜

正式失衡规则覆盖旧70°值，最大倾斜75°，3秒开始首轮目标，约每12秒选择新的倾斜方向；目标倾角从25°至75°。实际旋转带角速度和角加速度限制，不能把目标角当即时盘面角。[R12]

![失衡赛：倾斜盘面和当前位置共同决定是否继续追击。](<撞击王座_实机图_20261014/22_失衡赛倾斜圆盘.png>)

盘面摩擦覆盖为0.015，推荐半径110m、直径220m。世界坐标距离、局部盘面半径与落地高度都随倾斜变化。粘连持续5秒，玩家要判断何时交给坡面危机，而不是一获得就自动用掉。

### 10.5 收缩到了决战区，比赛仍继续

两模式在180秒内从初始半径收至`max(20m, 初始半径×20%)`，到达后继续交战直到团灭判定。圆盘、护栏、Buff位置、出生与HUD要读取同一实际半径，否则模型已经缩小，物理地面却可能仍在旧位置。[R12]

### 10.6 回合重置的内容

| 状态 | 下个回合怎样处理 | 漏清后会怎样 |
|---|---|---|
| 耐久／稳定／冲势 | 按该模式初始规则恢复 | 一方带上轮损耗开局 |
| 技能许可 | 失衡赛重新取得 | 上轮Buff永久解锁 |
| 反弹／粘连 | 清除已用与剩余状态 | 开局就携带护盾或抓坡 |
| 飞行返场 | 清除并回到出生条件 | 新局仍沿旧空中方向运动 |
| 随机倾斜 | 按回合种子初始化 | 新局继承最陡盘面 |
| 护栏开口 | 重新生成适用状态 | 永久缺口或重叠护栏 |
| 回合比分 | 保存整场比分 | 比分重置或重复加胜场 |
| 观战接管 | 退回玩家原控制身份 | 操作继续控制上一辆队友 |

### 10.7 少数存活者需要清楚局势

队伍剩余人数、谁有返场机会、谁还持有粘连或技能许可，比普通总击杀数更有用。玩家淘汰后可以选择观战或适用的队友接管，镜头和输入对象会变化，但账号与奖励身份应保留原玩家。[R10]

## 11 军团战争与AI协作

### 11.1 40对40改变信息密度

军团战争以消灭敌队为目标，支持草原、沙漠、雪原。80车带来的核心问题是局部接触、阵线、前后排和目标分配。每台AI都追同一个最近敌人，容易形成堵车；每台车都随机跑，则缺少前线。[R13] [R15]

![军团战争：大范围队伍阵线与局部战斗。](<撞击王座_实机图_20261014/24_军团战争团队战场.png>)

| 局部任务 | 所需能力 | 团队配合 | 观察指标 |
|---|---|---|---|
| 前排争路 | 承伤、质量、保护 | 后排利用空出的路线 | 拥堵、接触集中度 |
| 侧翼切入 | 机动、侧击、切割 | 前排先建立牵制 | 成功接触和脱离 |
| 守护反击 | 反射、恢复、护域 | 保护被围队友 | 被救对象后续可用时间 |
| 控场 | 固定圈、跟随圈、方向影响 | 把敌人留在可攻击区 | 圈内停留与友军收益 |
| 火力支援 | 炮击和视线 | 队友别挡住炮管 | 追瞄、遮挡与有效命中 |
| 收尾 | 识别低耐久目标 | 不让全队离开阵线 | 击杀收益与暴露风险 |

### 11.2 AI从意图开始

AIBehaviorRuntime采用行为树与效用层，按车型建立角色、风险预算和接近偏好，物理仍负责实现运动。当前角色包括控场、游击、正面对抗、撕咬、守护反击；模式再改变攻击、边缘、资源和撤退权重。[R13]

### 11.3 资源、接触与安全会争夺同一决策

大逃杀优先寻找配件和安全路线，经典更重接触目标，失衡需要先保落脚。低耐久撤退、边缘风险、可用技能和队友位置共同影响目标选择。如果只根据距离，AI可能离开补给点追一个即将掉落的目标，也可能向已经危险的坡面冲刺。

| 决策问题 | 输入 | 输出 | 常见失效 |
|---|---|---|---|
| 选敌人 | 距离、状态、车型、队伍 | 目标ID与承诺时间 | 每帧换目标，来回摇摆 |
| 选资源 | 价值、可达性、库存 | 资源目标和路线 | 追逐空洞另一侧的物品 |
| 接近 | 敌人朝向、法线机会、障碍 | 正面／侧面／后方点 | 地图坐标正确但支撑错误 |
| 用冲势 | 路线安全、资源、补给 | 开始、持续、终止 | 越过边缘后才取消 |
| 用技能 | 目标成立、范围、资源 | 一次施放 | 没目标也交关键能力 |
| 撤退 | 稳定、耐久、边缘、队友 | 安全落点 | 刹车和转向互相打架 |

### 11.4 协作要能看出来

共享黑板可以避免集中抢同一资源，分配前排、侧翼和保护任务。它是否有效，要看自然对局中的阵线和目标变化；代码里存在role字段，还不能证明每一辆车都表现出独特行为。

观察记录可保存目标持续时间、路径中断原因、无接触驾驶时长、救援行动与资源重复争抢。再用回放片段解释异常，才能决定改风险权重、路线还是技能条件。

### 11.5 当前缺少的真人协作证据

本轮确认本地AI及相关团队运行，未接入真人实时对战、匹配大厅或真实队伍通讯。策划案中的组队邀请、延迟补偿和竞争匹配，只能列为后续规格候选，不能放进现状功能清单。

## 12 生涯目标与一次结算

### 12.1 生涯正在记录哪些成长

当前生涯包含任务、成就、天赋、成长、图鉴和赛季等入口。账号等级、原型熟练度、地图记录、章节进度、通行证等级与永久收藏各有记录。玩家得到一次XP，并不意味着所有进度条都一起上涨。[R24]

![生涯：当前每日任务、周契约和本局目标。](<撞击王座_实机图_20261014/05_生涯与长期目标.png>)

| 进度 | 用途 | 典型来源 | 与其他进度的区别 |
|---|---|---|---|
| 账号等级 | 全局成长与阶段解锁 | 对局和生涯任务XP | 不直接等于通行证级别 |
| 车型／原型熟练度 | 记录参与和操作经验 | 使用该原型的对局 | 不等于已经精通该技能 |

| 通行证等级 | 赛季奖励资格 | 有效驾驶时长任务XP | 每级250XP，另有赛季时间 |
| 永久整车 | 可用战术工具 | 抽奖、碎片、通行证 | 目录出现不代表已取得 |
| 永久主题皮肤 | 收藏与装备选择 | 奖励、奖池或购买 | 缺对应整车时仍能保存 |

### 12.2 本局、每日、每周任务的不同职责

本局任务在开赛时随机3个，给一场攻击额外方向；每日任务3个，支持短访问；每周5个契约，把地图、原型和特殊行为放到更长周期。任务需要跟正常驾驶重合，否则玩家会为了计数放弃比赛目标。

| 当前画面中的任务 | 要求 | 奖励XP | 可以检查什么 |
|---|---|---:|---|
| 每日跨地图撞击 | 2张地图各一次有效撞击 | 45 | 是否鼓励了解地图，而非菜单来回切 |
| 每日完赛 | 完成2局 | 40 | 退出和正常结束是否区分 |
| 每日工具尝试 | 使用3种道具 | 45 | 是否真用而非仅拾取 |
| 每周淘汰 | 累计3名对手 | 110 | 功劳和队友误判 |
| 每周跨地图 | 4张地图完成有效撞击 | 100 | 原图和变体是否正确计唯一 |
| 每周机关 | 利用机关3次 | 90 | 机关参与的判定条件 |
| 每周原型 | 3种原型完赛 | 100 | 指定试炼与实际模型身份 |
| 每周低稳反击 | 稳定低于30时反击一次 | 80 | 反击动作与状态时间点 |

以上是本次新存档画面上的任务例子，不将其写成所有日期永久不变的抽选结果。任务结构与刷新频率可以从代码確認，具体集合需保存任务种子和周期ID。

### 12.3 有效行为需要可回溯

“有效撞击”应对应规则事件，而非两个模型曾接近；“借助机关”要说明是参与淘汰、主动利用还是仅被影响；“低稳定反击”应在相关行为时读取状态，而不是结算时再看稳定已恢复多少。

| 行为 | 合理记录时点 | 最少字段 | 易刷或误计的情况 |
|---|---|---|---|
| 有效撞击 | 碰撞事件确认 | 事件ID、对象、法向贡献、模式 | 静止贴靠持续刷计数 |
| 侧面破势 | 方向与稳定作用确认 | source、target、zone、前后稳定 | 视觉从侧面看不等于判定侧面 |
| 道具使用 | 成功消费并生效 | itemId、slot、对象、时间 | 未取得时按键也算使用 |
| 机关参与 | 机关实际影响事件 | mechanismId、阶段、对象 | 看了预警就记一次 |
| 淘汰 | 最终淘汰确认 | 原因、归因、sessionId | 多来源重复发事件 |
| 完赛 | 会话结束并确认 | mode、结果、终止原因 | 中途退出算正常完成 |

### 12.4 结算把过程转成哪些资产

对局结束可能更新胜利数、淘汰类型、任务、地图进度、经验、废铁、徽记和日首胜券。生涯和经济分开维护，可以降低相互耦合，但也需要一个可靠的完赛身份去重。[R17] [R24]

```wz-diagram
完赛结果|对局结束>结果与归因;结果与归因>生涯任务;结果与归因>经济结算;生涯任务>等级与记录;经济结算>库存确认;库存确认>奖励展示
```

本轮尚未逐场核对全部结算分支的收益总量，因此不提供虚构的“每天稳定赚多少”。自然单局奖励、限次数奖励、活动奖励与测试期间全开便利，需要各自登记后再计算账号获取周期。

### 12.5 放弃对局与正常失败

失败仍可以有学习和任务进展，主动退出则需要记录退出原因。把二者同样记作完成，会鼓励快速开赛退出；完全否定失败所得，又可能让新手无法推进。策划案给出按结果、完成和中止分别处理的标准，现有奖励需按实际分支核对后沿用。

### 12.6 新手目标应教会一套可用动作

当前运行中的新手目标从正面撞击开始，之后加入侧面破势等行为。它与老生涯文案的10步、当前HUD的12步存在历史差别，最终教学应固定一个来源。把所有技能介绍完，也未必让玩家知道边缘处应该刹车。

入门链可以检查：能否保持地面支撑、看到边缘、控制接近方向、做一次有效接触、脱离恢复、使用冲势逃离。每一步都在真实任务里验证，文字说明只是辅助。

### 12.7 把长期参与拆成不同深度

每天登录、完成任务、试用新车型、稳定战术、做对照测试，代表不同参与。收藏玩家可能少打竞技；愿意训练的人可能不急着攒满所有外观。报告应看具体目标，没有玩家样本时不杜撰这些群体的比例。

## 13 经济资源与商品实际买到什么

### 13.1 当前货币均按虚拟资源解释

当前芯片商店列出高级通行证600芯片、单券120、五券540、废铁1000售价80芯片。规则文件明确使用赚取的虚拟芯片，未在本轮确认真实货币充值或支付SDK。商业化拆解因此讨论资源消费和长期商品设计，不能把这些数字直接写成人民币收入模型。[R20]

| 资源 | 当前主要用途 | 取得／消耗需要登记 | 判断价值的方法 |
|---|---|---|---|
| 芯片 | 高级轨、券、废铁及部分商品 | 具体奖励事件和购买 | 能提前哪个目标，放弃了什么 |
| 废铁 | 既有制作、外观或模块相关消费 | 生涯与重复补偿 | 是否还有可用消费对象 |
| 徽记 | 挑战相关目标 | 模式及挑战结果 | 是否必须进入特定玩法 |
| 抽卡券 | 一抽消耗一张 | 首胜、通行证、购买和抽中奖励 | 当前票量及缺券报价 |
| 车辆碎片 | 稀有／非专属泰坦兑换 | 重复整车及主奖补偿 | 距指定车辆还差多少 |
| 赛季XP | 通行证等级资格 | 周任务领取 | 能否赶上当前赛季 |
| 有效驾驶时长 | 周任务累计 | 活跃判定与前台状态 | 可由正常玩法完成的比例 |

### 13.2 同一货币面对多个目标

一个新存档当前有100芯片。它距离120单券不远，距离600高级通行证还有一段；买废铁后则会推迟这些选择。若玩家只看到“可购买”，却看不到余额和剩余目标，短期消费可能与长期计划冲突。

有用的经济展示包括余额、准确报价、永久／当季范围、已有库存和主要替代用途。它不必替玩家决定，但需要让选择基于清楚条件。

### 13.3 五券包如何参与缺券报价

单抽、十连会先计算已有券，再组合五券540与单券120补差。缺9券的十连为`540+4×120=1020`，缺10券则为1080；已有券不会再按整套十连扣一次。[R19]

| 计划抽数 | 已有券 | 缺券 | 组合成本（芯片） | 取消时 |
|---:|---:|---:|---:|---|
| 1 | 1 | 0 | 0 | 券数和余额不变 |
| 1 | 0 | 1 | 120 | 余额不变 |
| 10 | 0 | 10 | 1080 | 不先发券再扣回 |
| 10 | 1 | 9 | 1020 | 券和余额不变 |
| 10 | 5 | 5 | 540 | 不多收另五券 |
| 10 | 9 | 1 | 120 | 最后确认仍查最新报价 |

### 13.4 日首胜券的节奏

当前本地分支按日记录首胜，一天首次胜利可以取得一张券；训练或试驾不应误发正常胜利券。日期刷新、跨午夜、同一结果重复处理需要用稳定的日ID和完赛身份去重。[R17]

若游戏未来接入服务器，日边界应由服务器统一。当前本地UTC日期计算和中文界面日期的用户理解可能不同，需要在产品规则里说明，不能从机器本地时区随意改出两套领奖日。

### 13.5 碎片兑换给指定目标留下路线

当前稀有整车兑换为300碎片，适用泰坦800碎片，普通车和骑刃王、泰坦坦克、天启不在该兑换范围。重复掉落因此可以转到一个确定目标，但专属奖励仍保持自己的获取路径。[R17]

| 重复结果 | 当前去向 | 对玩家选择的作用 |
|---|---|---|
| 普通整车重复 | 20碎片 | 渐进积累，但该类别优先未拥有 |
| 稀有整车重复 | 50碎片 | 接近指定稀有兑换 |
| 一般泰坦重复 | 100碎片 | 接近适用泰坦兑换 |
| 骑刃王重复、有缺皮肤 | 对应永久皮肤自选 | 收藏本车主题 |
| 骑刃王及皮肤全重复 | 100碎片 | 回到通用兑换 |
| 皮肤类别全重复 | 该皮肤价格对应废铁 | 保留资源出口 |

### 13.6 经济复杂度如何控制

多个钱包、重复补偿、双轨奖励和服务器状态，让玩家容易把“奖励已展示”误认为“资产已确认”。所有加减都需集中到库存事务结果，界面负责解释，动画负责呈现。经济扩展可以增加商品，不能同时增加多处各写一个余额的实现。

## 14 28天通行证的排程

### 14.1 四周恰好填满100级

当前通行证28天、100级，每级250XP，总计25000XP。每周达到30、60、90、120分钟有效驾驶时长，分别领取1500、1500、1500、1750XP；一周合计6250XP，四周正好25000XP。规则为玩家提供了明确完成目标。[R18]

![通行证：免费与高级轨同时可查看，取得不会自动装备。](<撞击王座_实机图_20261014/08_通行证双轨.png>)

| 每周累计时长 | 本节点XP | 累计XP | 对应累计等级 |
|---:|---:|---:|---:|
| 30分钟 | 1500 | 1500 | 6级 |
| 60分钟 | 1500 | 3000 | 12级 |
| 90分钟 | 1500 | 4500 | 18级 |
| 120分钟 | 1750 | 6250 | 25级 |
| 四周均完成 | 25000总XP | 25000 | 100级 |

它奖励的是有效参与时间，不承诺“每周打开游戏两小时就完成”。玩家在前台驾驶、有输入或有效运动的条件才会影响累计，暂停、后台和长时间无输入另判。

### 14.2 当前有效计时怎样筛选

实现每秒检查实际驾驶状态，页面可见、加载未阻塞且最近60秒内有适用输入。持续按键还需与运动一起看，避免把完全卡住或纯菜单等待算成游玩。训练可以计入主动驾驶时长；胜利券则遵循另外的完赛规则。[R17]

| 情况 | 当前需要核对 | 玩家应得到的说明 |
|---|---|---|
| 正常驾驶 | 输入和位置变化 | 当前累计正在增长 |
| 主动训练 | drivingState与训练条件 | 可以练车推进时长 |
| 停着看地图 | 最近输入窗口 | 短停与长期离开不同 |
| 暂停 | 状态已变 | 暂停期间不累计 |
| 后台 | document.hidden | 返回后从当前状态续计 |
| 加载 | LoadingCoordinator.blocked | 不把加载时间算玩法要求 |
| 自动追撞 | 驾驶与有效输入判定 | 是否可计按当前规则说明 |

### 14.3 错过前周仍有补齐空间

时长先填当前周，再用剩余有效时长补当前之前仍缺的周，每周最高7200秒；未来周不能提前领取。回流者不必严格每七天完成一次，却仍要承担整个赛季累计时间。界面应把“当前周”和“可补前周”并列说明。[R18]

![周任务：四周的时间门槛、领取状态与XP。](<撞击王座_实机图_20261014/26_通行证周任务.png>)

例如第四周才加入、所有周均为空，理论仍需480分钟有效参与。这是规则演算，未测普通玩家完成这些时间的疲劳和间断；不能直接将它称为轻松补赶。

### 14.4 双轨的永久结果

免费与高级各有19个阶段皮肤节点，共38套里程碑皮肤；两条轨在100级提供不同整车。免费100级含泰坦坦克与适用券奖励，高级100级提供天启。高级轨目前600虚拟芯片解锁。[R18] [R20]

![100级奖励预览：两条轨的整车目标不同。](<撞击王座_实机图_20261014/27_通行证100级整车.png>)

皮肤和整车进入永久权益，赛季是否高级、当季XP及领取资格则属于赛季记录。奖励不会自动替换出战车辆或涂装，让玩家可以领取后自行决定何时使用。

### 14.5 重复奖励分流

| 奖励 | 尚未拥有 | 已拥有部分 | 全部对应内容已拥有 |
|---|---|---|---|
| 整车大奖 | 取得永久整车 | 转为对应车型皮肤自选 | 600芯片与5券补偿 |
| 里程碑皮肤 | 取得该永久皮肤 | 优先同车未拥有皮肤 | 按原皮肤价格补废铁 |
| 旧版已领资源的里程碑 | 资源不重复发 | 补新皮肤／适用新增车权 | 按迁移条件处理 |
| 赛季结束未领取 | 按有效等级与高级资格自动补领 | 保留领取日志 | 不重发历史领取 |

通行证整车全重复补偿与抽奖主奖补偿不同。前者为600芯片加5券，后者为100碎片，两种去向不能共用一句“重复返还碎片”。

### 14.6 领取与表现分开

奖励要先确认资产，再播放结果；已领取节点显示记录而非继续可点。批量领取、跨赛季自动补领和网络重试应保留操作身份。无论玩家何时关闭动画，权益只处理一次。[R17] [R18] [R21]

### 14.7 这一机制的长处与负担

各周要求固定、奖励可预览，玩家能安排目标；补前周也留出弹性。限制则是时间累计不会直接证明有趣：认真练习、重复资源路线和为了时长继续驾驶，都可能得到相同XP。观察应比较玩家原目标、主动选择和领取后的使用，不能只看满级率。

## 15 十类永久奖池与保底

### 15.1 类别概率与对象概率

当前先抽类别，再从该类别的未拥有对象中优先选择；类别都已拥有时才进入重复处理。表中的20%普通整车属于类别概率，不是每辆普通车各20%。骑刃王主奖仅对应一辆整车。[R19]

![特别池：十类结果同时给出概率和剩余未拥有数量。](<撞击王座_实机图_20261014/10_抽奖十类奖池.png>)

| 类别 | 概率 | 内容 | 类别内选择 |
|---|---:|---|---|
| 骑刃王 | 1.5% | qrw永久整车 | 主奖唯一对象 |
| 普通整车 | 20% | 18车目录中的适用普通 | 优先未拥有 |
| 稀有整车 | 18% | 18车 | 优先未拥有 |
| 一般泰坦整车 | 6% | 排除titan、apoc、qrw后的17车 | 优先未拥有 |
| 普通永久皮肤 | 20% | 54套 | 优先未拥有 |
| 稀有永久皮肤 | 18.5% | 54套 | 优先未拥有 |
| 泰坦永久皮肤 | 6% | 80套 | 优先未拥有 |
| 芯片 | 3% | 60芯片 | 固定数量 |
| 废铁 | 5% | 1000废铁 | 固定数量 |
| 抽卡券 | 2% | 1券 | 固定数量 |

概率合计100%。一般泰坦类别排除三辆专属车，不能据总目录20辆计算每车独立概率。皮肤类别可包含尚未拥有整车的皮肤，获取与装备分别判断。

### 15.2 第60抽怎样触发

连续未中主奖计数达到59，下一抽强制主奖；普通抽提前中主奖则重置计数。十连顺序执行，每一抽都会更新保底，可能在十连中间先触发一次主奖，再从零继续。[R19]

| 抽前连续未中次数 | 本抽结果 | 抽后计数 | 解释 |
|---:|---|---:|---|
| 0 | 非主奖 | 1 | 普通累计 |
| 58 | 非主奖 | 59 | 下一抽达到强保底 |
| 59 | 强制主奖 | 0 | 第60抽保底 |
| 25 | 随机命中主奖 | 0 | 提前命中重新累计 |
| 十连从58开始 | 前两抽依次更新 | 逐抽判断 | 不在十连结束才统一判断 |

### 15.3 保底前后的概率直觉

若只看前59次独立普通主奖机会，至少一次随机主奖的概率为`1-0.985^59`，约59.0%；剩余约41.0%的玩家序列会走到第60抽强保底。这是假设每次普通类别独立的计算，适用当前核心随机分支，实际分布还要由样本检验。

首次主奖抽数的期望为`(1-0.985^60)/0.015`，约39.7抽。期望表示长期平均，不等于个人第40抽一定得到。把这些值与实际可赚券和芯片配在一起，才可以讨论目标需要多久；本轮没有自然收益样本，暂不换算天数。

### 15.4 未拥有优先缓解哪种重复

类别一旦选定，未拥有优先减少同类别早期重复。它没有改变该类别被选中的总概率，也没有保证十连中一定包含稀有或泰坦。玩家可以更稳定完善类别收藏，但仍可能连续抽到自己暂时不需要的资源类别。

### 15.5 抽前报价和抽后动画

当前缺券时先报价并确认。库存事务通过后，结果已经写入，再开始转动、揭示或十连展示；跳过动画只缩短表现，不重新抽奖、不改变结果。芯片不足或取消，都应保持原库存。[R17] [R19] [R22]

### 15.6 主奖取得后的收藏延续

主奖重复时，若骑刃王还有未拥有主题皮肤，生成一次对应自选；所有对应皮肤都已拥有后，转100车辆碎片。选择时再次检查皮肤是否已拥有，避免另一个操作已经获得同皮肤后仍重复授予。[R19]

| 情况 | 操作结果 | 还要保留什么 |
|---|---|---|
| 首次骑刃王 | 永久整车 | 主奖历史和保底重置 |
| 重复骑刃王有缺皮肤 | 自选请求 | choiceId、候选列表和来源 |
| 自选期间获得候选之一 | 更新可选资格 | 不丢失整个请求 |
| 候选全部已取得 | 适用补偿 | 只补偿一次 |
| 无对应缺皮肤 | 100碎片 | 不附送错误的自动装备 |

### 15.7 存储失败不能只关掉窗口

核心抽奖在库存副本上演算，发布前需确认持久化成功。本地存储不可写、服务拒绝、报价变化或奖池版本变化都可能使事务失败。结果界面应明确没有发生本次扣取，并保留重试上下文，不能照常播一段中奖动画后再发现存档没了。

### 15.8 永久奖池的后续内容成本

永久收藏可以持续吸引玩家补齐内容；目录扩展后，类别内概率、未拥有统计、重复补偿、碎片兑换和版本身份都会受到影响。新增一辆车需要一起更新这些地方。特别车路径要保持一致，不能在一个版本里既写通行证唯一，又把它放进一般泰坦随机类。

## 16 本机存档、账户与同步

### 16.1 当前入口先处于本机模式

新浏览器显示本机试玩存档，经济状态为offline-local，未连接账户服务。项目已有账户界面、独立服务与同步逻辑，可以研究事务规则；本轮没有登录作者账号，也没有以此确认线上发行服务已达标。[R17] [R23] [R28]

![账户页：本机与联网账户的资产状态需要分别显示。](<撞击王座_实机图_20261014/13_账号与本机存档.png>)

### 16.2 两套库存不能随意合并

本机试玩进度与账户库存独立。连接后交易依服务回复确认，断线也不能把本地临时增加直接当服务器权益。否则用户切设备时可能重复获得车和资源，或将旧库存覆盖新库存。

| 状态 | 资产依据 | 可显示 | 待确认内容 |
|---|---|---|---|
| 本机离线 | 本地已保存库存 | 本机余额和权益 | 不宣称已同步 |
| 正在连接 | 原有模式库存 | 连接状态和重试 | 不把请求当登录完成 |
| 服务已确认 | 服务器库存与revision | 已确认资产 | 发送中的操作单列 |
| 网络中断 | 最后确认库存 | 缓存及连接错误 | 不预发新权益 |
| 操作冲突 | 服务拒绝与新版本 | 冲突原因 | 核对后重报价 |
| 退出账户 | 按模式切回本机 | 当前库存来源 | 不把两套余额相加 |

### 16.3 一个操作身份防止重复发奖

抽取、购买、领取和换皮肤都有操作ID，记录类型和参数指纹。同ID、同参数重试返回原结果；同ID被拿来做别的交易应拒绝。动画、窗口关闭和请求超时均不创建第二份权益。[R17] [R23]

### 16.4 同步需要版本和结果身份

服务revision判断库存是否过期，奖池版本判断本次抽取对象，赛季ID判断领取范围，会话ID判断完赛。这些身份解决不同问题，不能共用一个“版本号”。玩法参数版本也应保留，用来解释同一车在更新前后的表现。

### 16.5 当前结论的适用范围

确认的是源码里的事务设计、可见账户页和本机行为。多设备同时交易、长期断线、恶意重放及生产数据库恢复仍需独立测试。本册不提供真实转化率、收入和账户活跃人数，也不将虚拟芯片购买称为已接入付费。

## 17 画面要帮助玩家判断下一次接触

### 17.1 大厅的信息已有自己的重心

当前大厅把出战车辆、开始游戏、成长与收藏放在同一张工业控制台上。橙色用于主要操作，暗色金属面承载车辆，通行证和抽奖各有独立入口。它能让玩家在开赛前看见当前车，也把收藏动机留在旁边。[R01]

这种结构最需要核对的是状态一致性。大厅展示车、车库选择车、备战确认车和实际生成车必须属于同一个选择过程。领取新车只应增加可用内容，不能在玩家不知情时把已确认的配置换掉。皮肤预览同样要能退出并恢复原配置。

| 界面位置 | 玩家此刻要做的决定 | 应显示的状态 | 容易造成误解的情况 |
|---|---|---|---|
| 大厅 | 继续比赛还是调整配置 | 当前车、模式入口、未处理奖励 | 车辆模型与实际出战ID不同 |
| 车库 | 选哪辆车 | 车型、能力、可用和收藏状态 | 全目录被写成全部拥有 |
| 工坊 | 如何取舍 | 当前模块、收益代价、最终结果 | 只给收益，隐藏操控损失 |
| 备战 | 本局使用什么 | 模式、地图、车辆、规则覆盖 | 团队禁技能没有提前说明 |
| 通行证 | 继续玩什么 | 周进度、可领项、赛季时间 | 经验条与可领状态不同步 |
| 抽奖 | 是否消耗资产 | 券、补券价、保底、概率 | 按钮显示十连但扣费条件不清楚 |
| 账号页 | 资产存在哪 | 本机／账号、连接和待确认 | 离线余额被当成服务器资产 |

### 17.2 车库数值要能解释驾驶体验

耐久和稳定上限适合静态对比。抓地、旋转阻尼和技能条件则必须放进具体环境：低摩擦面、急转、接地、受击后分别怎样变化。当前来源页已经提供计算链，继续完善时应让数值和文字读的是同一份结果。[R03] [R04]

`×1.00`与`+0%`都可以表达不变，但`×0.0%`会让人以为这个属性失效。本轮看到的这种格式错误应直接修正。它虽然不一定改变车的物理行为，却会让玩家基于错误理解换车或改模块。

参考速度还需要改名并附单位。无硬上限驱动中，车会受推力、阻力、场地和技能共同影响；把一个参考值标为最高前进速度，后续实际跑得更快就像数据出错。应同时说明该值用于比较基准，实际速度在HUD里观察。

### 17.3 HUD需要随玩法换问题

经典赛主要看位置、存活者、耐久、稳定和冲势。撞飞赛多了燃料、反弹与返场机会；失衡赛要读倾角、滑移和粘连；大逃杀则要看队伍、进化材料、配件和空洞。沿用一套面板可以降低学习成本，但同一位置展示的含义必须跟模式变更。

| 模式 | 最紧迫的问题 | 首要信息 | 次要信息 |
|---|---|---|---|
| 经典 | 这次撞击后还能不能回场 | 位置、边缘、稳定、冲势 | 击杀、任务、累计伤害 |
| 大逃杀 | 该打、该拿还是该撤 | 队伍、资源、当前品质、地形 | 收藏和局外等级 |
| 撞飞赛 | 有没有有效法向命中与返场余量 | 燃料、反弹、空中方向、回合比分 | 普通车技能说明 |
| 失衡赛 | 现在朝哪边滑，能否重新落脚 | 倾角、技能许可、粘连、盘面边缘 | 长期任务进度 |
| 军团 | 前线在哪，我的目标是谁 | 敌我、目标、队友状态、局部威胁 | 全场逐车完整数值 |
| 训练 | 刚才发生了什么 | 靶状态、事件、伤害和方向 | 赛事排名 |

模式提示应在开局确认时出现，比赛内只保留需要即时响应的变化。玩家正在转向时，再弹一段详细规则，会遮住同一段路。

### 17.4 镜头改变了玩家看得到的机会

当前已整合`wheel-overhead-20261014.2`：第三人称滚轮缩放下限0.75，上限按当前地图动态取`max(8, min(60, 地图边缘半径×0.2))`，向后可逐步进入俯视；第一人称向后滚动可退出到第三人称。Q切换视角，部分坦克还可在第一人称用V切换座舱与炮塔。观战战术镜头可用滚轮返回跟车；高位镜头同步调整裁剪面、雾和天空范围，切换控制或离开对局时恢复原环境。[R03] [R10] [R26]

近景能读接触和车体方向，俯视能读落脚区和敌群，第一人称适合体验车体与瞄准。它们提供的信息量不同。对于追求精确绕侧的玩家，远镜头常常比外观细节更重要；对于炮击，镜头与射线起点不一致又可能出现“看见了却打不到”。

| 镜头情境 | 要核对的关系 | 可接受的反馈 |
|---|---|---|
| 第一人称切第三人称 | 眼点不能穿过实体护甲 | 直接切到合法终点，再稳定跟随 |
| 远距俯视 | 车头、队伍、边缘仍可辨认 | 缩放后保留关键标识 |
| 坦克炮塔 | 准星、炮口、遮挡相符 | 受阻时提示炮口遮挡 |
| 被撞翻滚 | 画面与控制恢复相符 | 不因镜头翻转再次误导输入 |
| 淘汰观战 | 镜头对象与控制身份分开 | 名称、队伍、观战／接管清楚 |
| 重开或换回合 | 清除旧对象偏移 | 新出生点可见且焦点正确 |

俯视取景可以用于检查地图，但它不替代正常驾驶视角的可读性检查。地图的危险如果只有把镜头拉到极远才能看清，新玩家仍会在普通距离下误判。

### 17.5 锁定辅助需要说明它改变什么

LockonDriveRuntime参与目标追踪与驾驶辅助，不能把其收益全部算到基础转向。开启、解除、目标淘汰、视线变化以及操控接管，都要留下清楚状态。[R14]

玩家主动锁敌后，系统可以帮助维持目标方向，但不应隐去危险的自动输入。特别是在窄桥、失衡圆盘和空洞边缘，朝敌人转过去可能比不攻击更危险。分析锁定辅助要分别记录目标是否正确、运动是否安全和玩家是否理解解除方式。

### 17.6 触屏同时操作比按钮数量更重要

移动控制运行模块已挂载。其实际体验还需在真机测量摇杆与冲势、技能、视角、道具的同时操作；本轮桌面浏览器截图不能证明触屏跟手。输入规则应按动作维护，再映射键盘和触摸，避免两端对同一技能采用不同消费或冷却条件。[R01]

触点被浏览器取消、窗口失焦和菜单弹出后，都应清掉持续前进与冲势输入。玩家抬手后车仍冲出去，会被认为是车辆难控制；实际原因可能只是输入状态没有释放。这个问题需要观察事件，不能靠降低速度解决。

### 17.7 音效与特效要指出原因

碰撞声、刃口转速、护盾破裂和冲势段位可以帮助玩家判断机制。相同的大火花如果同时代表普通撞击、被护盾吸收和切割，就会掩盖结果。效果应跟随已确认的接触、伤害或保护事件，不独立改变耐久。[R05] [R06] [R07]

| 事件 | 画面需要说明 | 声音需要说明 | 不应混淆 |
|---|---|---|---|
| 普通接触 | 撞击点与方向 | 轻重差别 | 每次接触都被表现成高伤害 |
| 有效切割 | 刃口与目标接触 | 持续咬合及中断 | 仅转得快却没有接触 |
| 保护成功 | 来源、吸收、剩余状态 | 一次成功提示 | 无敌等于没有物理碰撞 |
| 稳定归零 | 操控受限及恢复 | 警告而非击杀音 | 与耐久归零混为一谈 |
| 冲势换段 | 当前段与资源趋势 | 少量关键变化 | 每帧重复发声 |
| 回合结束 | 胜负、原因、下局时间 | 与最终胜利分开 | 一小局被当成整场胜利 |
| 奖励确认 | 奖励身份及转换 | 一次确认 | 动画开始等于资产到账 |

### 17.8 性能预算保护哪些体验

当前物理以120Hz固定步推进，对局展示、HUD和非关键信息可采用较低更新频率。车库高细节与比赛LOD分离，大规模场景还用对象池、空间索引和减少隐藏界面工作来控制成本。[R03] [R05] [R27]

性能问题会改变玩家判断：输入响应迟、接触漏算、场地信息晚到都比火花少一点更伤体验。优化时先减少装饰、远景复杂度、不可见界面和重复查询，再检查是否动到碰撞、参与者和地形支撑。80车军团与48车大逃杀需要独立压力场景，8车经典通过不能代替它们。

配置中的目标60FPS、P95帧耗20ms、1280×720是预算目标。当前取图环境使用软件WebGL，没有提供达到这些目标的硬件测试证据。平均帧率也不能解释偶发接触卡顿，需要结合长帧、物理补步、输入时延和场景变化判断。

## 18 系统维护怎样落到数据和事件

### 18.1 生成入口需要追溯到可改的来源

正式HTML包含模型、材质、界面、逻辑和整合代码，适合离线运行。维护时却不能只改成品：下一次执行构建脚本可能把修改覆盖。当前构建从保留的底稿与侧载模块生成入口，再附加56车、模式和经济系统。[R02]

因此一个“数值改动”至少需要找到其配置来源、覆盖位置、运行结果与说明。仅搜索到旧CONFIG字段并改它，可能根本不影响现行M2驱动。反过来，直接改生成脚本中的最后一次赋值能生效，却可能让上游表和UI继续展示旧值。

| 内容 | 研究时采用的对象 | 制作时的主要落点 | 验证办法 |
|---|---|---|---|
| 车辆身份 | 注册结果和完整目录 | 车辆数据、绑定规则 | ID唯一、56车可解析 |
| 驱动与受击 | 有效M2及Physics配置 | 配置与物理模块 | 运行快照和接触场景 |
| 主动技能 | 当前解析定义 | 技能实现与车型参数 | 施放、命中、中断、重置 |
| 地图 | 支撑、危险和展示 | 地图定义与模式覆盖 | 可达路线和落脚一致 |
| 通行证 | 当前赛季和奖励表 | Core、UI、经济事务 | 领取结果及迁移 |
| 抽奖 | 最终十类池 | Core、目录、账户服务 | 概率、保底、重复、扣费 |
| 说明文字 | 玩家可见页面 | 由相同数据生成 | 和运行字段逐项核对 |
| 离线入口 | 构建输出 | 构建脚本与资产输入 | 哈希、启动、无丢失依赖 |

### 18.2 参数需要单位和所属阶段

“速度+20”“范围48”“减伤0.3”如果没有单位与作用点，讨论很快失焦。速度可能是m/s或km/h，范围可能是半径或直径，0.3可能是减去30%或保留30%。当前文档按配置实际作用解释，执行册则把字段、单位、来源和边界一并写进表。

复杂属性还需要记录它是在base阶段、原型倍率、常驻天赋、模式覆盖还是临时状态生效。同名字段的最终值和参与计算的中间值可能不同。诸如动量预览仍沿旧速度阶段计算的情况，应标明目前不能作为新驱动下的精确战果预测。

### 18.3 事件契约比页面按钮更接近规则

当前事件包括稳定变化、技能预警、技能命中、冲势变化和撞击结果。拆解时应沿事件找到真正写状态的位置：谁判定有效，谁扣资源，谁结算伤害，谁只负责播放效果。[R03] [R04] [R05]

```wz-diagram
一次有效事件|输入意图>规则允许;规则允许>状态修改;状态修改>结果事件;结果事件>HUD与音画;结果事件>训练记录;结果事件>对局统计;对局统计>结算条件
```

同一事件可被多个系统读取，但资产领取应有单独的事务身份。把“播放了胜利动画”当成发奖信号，会在重播、返回页面或恢复窗口时多发；把物理求解每个触点当成一次完整攻击，也会在一对车辆持续贴住时连续过量伤害。

| 事件信息 | 作用 | 缺少以后难以解释的事 |
|---|---|---|
| 对局／回合ID | 划分一次比赛和一次小局 | 重开与重复结算 |
| 来源与目标ID | 指定攻击和受击对象 | 队友、假身和反射归属 |
| 接触点与法线 | 解释碰撞方向 | 为什么高速擦过伤害低 |
| 命中前后状态 | 解释实际损失 | 护盾、上限和反射差别 |
| 技能／道具来源 | 说明额外变化 | 同一圈效果来自哪辆车 |
| 时间与采样阶段 | 排序并复核 | 同帧淘汰和技能结束 |
| 参数／池／赛季版本 | 重现规则 | 更新后的旧记录无法还原 |

### 18.4 预览目录与战斗目录需要共用身份

外观展示工厂、比赛LOD、碰撞包络、主动技能和经济奖励都引用vehicleId。别名负责兼容旧存档，不能出现一辆车在车库叫新ID、奖励还发旧ID却找不到模型。当前绑定对legacyId做映射，继续扩车时应在发布前检查这条链。[R03]

皮肤也要使用稳定skinId，显示名可改，历史资产身份不应随文案变化。抽奖以名字去重会在更名时重新发相同外观；通行证按页码存领取记录，则会在调整奖励位置后误认领取状态。

### 18.5 测试需要挑会改变结果的组合

随机开几局容易碰到普通路径，却漏掉保护同时触发、贴边复活、控制对象切换和十连中途出主奖。测试设计应围绕状态交界挑组合，不需要把56辆车的每一套外观都跑遍同样的场景。

| 组合 | 选择原因 | 要记录的结果 |
|---|---|---|
| 普通正撞与斜擦 | 法向贡献不同 | 接触法线、损失、后续轨迹 |
| 反射遇反射 | 存在递归风险 | 最大反射深度、来源归属 |
| 切割碰正面防切 | 区域与伤害类型同时判断 | 扣除方向与剩余状态 |
| 无敌车被推到边缘 | 防伤与掉落分开 | 是否仍可淘汰 |
| 银脊归零并临近空洞 | 耐久恢复与支撑分开 | 次数、落点、继续存活条件 |
| 团队全灭同时发生 | 赢局条件竞争 | 是否重赛、是否误增比分 |
| 大逃杀换品质时有配件 | 对象重绑与局内成长 | 配件、队伍、状态保留 |
| 抽奖第60抽在十连中部 | 顺序结算与保底重置 | 后续抽按新计数继续 |
| 赛季结束时未领大奖 | 自动领取与重复选择 | 唯一授予、待选保留 |
| 请求超时后重试 | 事务可能已经成功 | 同ID返回相同结果 |

### 18.6 维护记录要保留实际结果

验收记录至少应包含版本、条件、操作、结果、截图或事件和失败原因。状态分为已实现、已观察、已验收、待补证；这几个词不能互相替代。一次截图证明页面可见，一次参数检查证明数值来源，完整生命周期还需开局、退出、重开、再进和结算。

本轮只建立两册文档和证据图，没有替项目完成上述全部验收。执行册提供的用例由制作人员继续执行，不能因为用例写好了就勾成通过。

## 19 当前问题按影响顺序处理

### 19.1 首先统一规则与显示

当前玩法已经覆盖驱动、56车、多个模式和经济循环。最直接的缺口集中在不同年代的规则与说明同时保留：旧速度上限、旧团队倾角、旧骑刃王获取描述、早期抽奖帮助文字和最终十类池可能给出不同答案。这些冲突会让已有内容显得不可靠。

| 编号 | 证据状态 | 当前问题 | 玩家／制作影响 | 处理顺序 |

这里的“高”表示影响玩家理解或后续制作，并非已确认会崩溃。网络并发、完整比赛掉帧和自然成长仍需测量，不能写成已发现的线上事故。

### 19.2 收藏价值需要对应明确的权限

当前普通18车可直接参赛，稀有和泰坦由拥有状态授权，经济收藏则记录实际取得的车辆。因此玩家能用某辆普通车，并不意味着已把它收进账号收藏；抽到未拥有的稀有或泰坦，会增加对应出战权限。训练试驾另走临时体验流程。[R17] [R15]

继续制作应让目录、收藏、可出战和试驾分别有明确标签，并删除注册表中会被误读的全部开放说明。执行册沿用当前普通可用、特殊品质需拥有的策略，要求各入口引用同一许可结果；完善的是说明与一致性检查，不把已有许可接口写成尚未接入。

### 19.3 先让训练结论能回到对局

训练场已有不同靶车、事件记录和伤害窗口。下一步更有价值的是让它回答具体问题：同一车斜擦为何低伤、某个模块如何影响回正、固定圈到底覆盖哪里。静态靶和实战运动仍不同，所以结果应保留条件，随后在移动对手和真实地图里复核。

车辆说明也可引用这样的练习入口。玩家看完“需正面有效命中”后可以直接试一条固定路线，看到接触角度和损失变化；相比再写一页百分比，操作和结果的关联更容易记住。

### 19.4 系统继续扩张前要清理身份

当前同时存在车型、原型、品质、主题外观、局内进化、账户拥有、出战选择和观战控制对象。它们都可能叫“当前车”，却负责不同事情。新增模式或奖池前应明确每个字段归属，尤其不要让接管AI后把奖励发给该AI车型，或让大逃杀进化把局外收藏状态永久改掉。

### 19.5 暂不靠猜测修平衡

56车看上去有清楚的分工，参数也提供了差异，但本轮没有公平条件下的胜率、技能命中率、淘汰原因和玩家选择数据。重车正面强并不直接等于过强，切割伤害高也不直接等于好用。暴露时间、接触机会、落脚和技能失败都要一起看。

建议先挑典型对照，再扩覆盖：重锤对平衡检验正面压制，旋刃对防切检验方向与持续接触，机动对控场检验逃离时间，保护对悬空检验规则边界。每组固定地图、构筑和输入条件，把结果写进统一记录后再调数值。

## 20 六个具体问题的推演

本章使用当前规则搭建分析例子，均为条件推演，不是本轮实测胜率或玩家访谈。

### 20.1 高速斜擦为什么没有期待中的伤害

假设两车接触前的表显速度相近，一次接触更接近正撞，另一次沿车侧擦过。后者的运动主要沿切线方向，法向贡献较低。物理仍会改变姿态，但耐久扣除采用自身攻击贡献、阈值与方向判断，不能直接用表显车速相除预测伤害。[R05]

检查顺序是接触法线、双方沿法线速度、攻击方自己的贡献、命中区域、保护来源和伤害前后状态。如果先认为“这车太弱”而增加全局伤害，会把正面接触也一起放大，并破坏低速顶推与持续切割的关系。

### 20.2 稳定归零后为什么还活着却转不回来

耐久决定是否撞毁，稳定决定受击后的可控程度。稳定归零不等于车辆被删除；可操控状态、冲势许可、恢复等待和地形仍共同决定能否脱离。若玩家只看到耐久，容易认为输入失效。

这时应展示稳定归零与恢复，而非给所有按钮一个模糊的禁用色。回正过程还要区分地面低摩擦滑移和控制锁定；前者需要改变方向与抓地，后者需要等待状态解除，两种提示不能共用“请重试”。

### 20.3 固定控场圈为什么需要读地形

风暴圈设在施放点，半径48m，对停留达到阈值的目标产生控制。敌人若能沿安全路线离开，施放收益下降；若圈放在窄桥与补给区附近，目标更难同时保落脚和脱离。固定圈把选择提前到施放位置，跟随圈则把选择放在追击路线。[R07]

设计研究应记录圈内停留、敌人的出口、友军能否利用控制，而不是只看一次施放命中了几辆车。一个覆盖多车但没有队友能接上的圈，可能不如覆盖一车却封住最后落脚路的圈。

### 20.4 失衡赛的粘连为什么要留到特定时刻

粘连持续5秒，能够临时提高落脚能力。开局立即使用可能在倾角还小的时候耗尽；滑到边缘才用又可能没有足够支撑让效果起作用。这里的决策由盘面趋势、位置、速度和目标倾角共同决定。[R10] [R12]

说明文字可以先交代“用于短时抓住盘面”，训练则比较早用、危险前用和已经脱离后用。不能让保护图标暗示掉出平台以后还能凭空吸回去，除非规则明确提供那种能力。

### 20.5 十连中间抽到主奖以后怎样继续

假设保底计数已到55，本次提交十连。前几抽若没有主奖，第60次对应的位置必须给主奖并重置；若更早自然抽中，则提前重置，后续抽按新计数继续。整笔交易的十个结果顺序固定，跳动画不重新随机。[R19]

验收应保存每抽前后计数、奖励ID和消耗，同一交易重试仍返回同一组结果。只看最后计数能发现一些错误，却不能解释提前出主奖时到底在哪一步重置。

### 20.6 四周任务怎样支撑通行证100级

每周四项共6250XP，250XP一级，因此一周对应25级；四周总计25000XP，恰好100级。30、60、90、120分钟是同一周有效游玩累计门槛，达到120分钟就满足四项，不需把它们相加成300分钟。[R18]

一周玩够120分钟、按规则领取全部任务经验，是这条计算路径的前提。暂停、加载、后台或长期无有效输入不计入，后期开启的周还未开放。当前补记会先填本周再补早周缺口，因此错过一周后的补玩路径要结合当前周进度解释。

赛季跨界时还需单独验证自动领取、重复整车选择和已领标记。数学总量等于100级，只说明任务表能够覆盖总XP，不证明所有玩家都会完成或满意。

## 21 拆解所得的制作结论

《撞击王座》已经有几条很具体的玩法支点：正面与侧向接触的取舍，稳定与耐久的双层受击，分段冲势，56辆车的能力差异，以及不同模式对技能和场地的覆盖。长期系统又用车辆、皮肤、任务、通行证和抽奖连接到重复游玩。

继续制作最该保留的是这些选择之间的因果。撞击方向需要在结果中看得出来，技能失败需要能解释，地图危险需要留给玩家反应和落脚空间，奖励路径需要与实际权限相符。新内容若只增加一个更大的倍率，会挤压已有车型和操作的用途。

本册的主要发现可直接转入另一册执行稿：整理有效参数的归属，修正显示和获取说明，区分体验开放与收藏拥有，完善对局到经济事务的身份，再按具体组合验证规则。实际手感、整场稳定性、AI协作效果和自然成长速度仍需在对应环境测量；它们影响调参的最终方向。

## 附录D 跨系统检查：从玩家动作追到实际结果

### D.1 同一动作可能影响几套系统

本表用于研究和复盘，不是游戏已通过全部验收的清单。每项先固定条件，再沿实际状态变化追踪，避免看到一个数字就对整个机制下结论。

| 玩家动作 | 首先受谁约束 | 可能连带改变 | 应一起记录 |
|---|---|---|---|
| 选车并确认 | 模式与出战许可 | 模型、主动、被动、占地 | 选择ID、最终生成ID、许可原因 |
| 换模块 | 槽位定义与保存 | 驱动、接触、恢复、道具时间 | 原件、新件、取舍、最终计算链 |
| 持续冲势 | 能量、阶段、失衡和模式 | 加速、刃速、减速保护 | 输入、段位、消耗、触发次数 |
| 正面撞击 | 接触法线及攻击贡献 | 物理、耐久、稳定、归因 | 接触前后状态和保护来源 |
| 持续切割 | 刃口接触与区域防护 | 驱动削减、损伤表现 | 每秒预算、实际接触时长 |
| 释放控场 | 技能条件与空间 | 目标驾驶、稳定、队伍协作 | 圈位置、停留、离开、友军过滤 |
| 拾道具 | 容量与拾取范围 | 持有槽、任务、后续攻击 | 拾取对象、归属、满槽结果 |
| 大逃杀进化 | 材料配方与当前品质 | 车辆、模型、技能、配件 | 消耗、继承、队伍与当前状态 |
| 掉落 | 支撑、边界与模式 | 淘汰、返场、胜负、推落归因 | 最后支撑、攻击窗口、结果原因 |
| 接管队友 | 目标资格与观战状态 | 镜头、输入、HUD | 控制对象与账号身份分别记录 |
| 领取通行证 | 等级、轨道、季节、已领标记 | 收藏、币、券、自选资格 | 唯一奖励身份和重复处理 |
| 抽取十连 | 券、报价、池版本、事务 | 保底、收藏、补偿、历史 | 十个顺序结果与交易ID |
| 返回大厅 | 会话退出与对象清理 | 输入、事件、镜头、任务计时 | 是否重复挂监听或继续记时间 |

### D.2 先区分两种“错误”

如果一辆车在低摩擦面上滑出平台，先看是否符合驱动和支撑规则，再判断危险信息是否足够。规则成立而玩家看不懂，属于反馈与教学问题；规则宣称无敌但仍受结构伤害，则可能是状态优先级或类型过滤错误。两类问题的修法不同。

| 观察 | 先核对 | 若规则正确 | 若规则错误 |
|---|---|---|---|
| 高速没大伤害 | 法向攻击贡献、保护 | 解释擦碰与正撞差异 | 修攻击贡献／区域计算 |
| 按技能没反应 | 冷却、授权、目标、稳定 | 给明确拒绝原因 | 修允许条件和输入消费 |
| 明明有保护却掉落 | 保护类型、支撑、返场规则 | 说明防伤不等于回场 | 修模式允许的返场路径 |
| 任务没有增长 | 事件资格、取样时点 | 写明任务条件 | 修事件和任务接线 |
| 领奖后车型未更换 | 取得与出战选择 | 提供显式装备入口 | 修资产授予或选择状态 |
| 动画结束没有到账 | 事务结果、账号状态 | 显示待确认／失败 | 修结果归并和去重 |
| 车库数值与比赛不同 | 模式、临时态、计算阶段 | 展示差异来源 | 修预览与运行共用计算 |

### D.3 五段完整路径的研究任务

**路径一：普通车第一次参加经典赛。** 进入大厅，选一辆普通车，比较基础能力与构筑，确认经典地图，启动并完成一次接触，退出后再进。观察许可、选择身份、出生、驱动、受击提示和退出清理。收藏只有一车的存档仍可使用普通目录，是这条路径的关键条件。

**路径二：试驾未拥有的泰坦。** 从目录选择特殊品质，进训练试驾，施放专属能力并退出。核对试驾是否还原正式出战车和皮肤，以及经济收藏是否没有被体验操作改变。模型能显示和主动能试用都不等于永久获得。

**路径三：失衡赛取得技能许可。** 开局先尝试F，在未授权时观察拒绝提示；拾取许可后再施放；暂停、恢复、结束小局再进入下一回合。许可、冷却与技能效果是三层状态，下一回合不应继承上回合资格。

**路径四：大逃杀进化。** 起始普通车拾配件、满足配方、进化并继续驾驶。检查品质和模型改变、配件保存、原有队伍、耐久／稳定处理、输入和镜头，再核对退出后账号收藏未受局内换车污染。

**路径五：已有主奖的账号抽到重复主奖。** 使用专门测试资产与固定结果，观察对应车未拥有皮肤的自选路径，以及皮肤齐全后的碎片补偿。刷新和同ID重试不增加第二份资格。这个测试存档的结果只能说明重复处理，不能表示自然抽取速度。

### D.4 平衡研究需要哪些样本

后续样本按模式、地图、车型、构筑、天赋、输入方式和经验分层。把训练靶、AI与真人结果混在一起，会使数据解释失去条件。少量极端个案适合查规则，不适合直接计算全局胜率。

| 研究问题 | 主要记录 | 为什么不只看胜率 |
|---|---|---|
| 重车是否压制所有选择 | 正面成功、绕侧成功、恢复、坠落 | 重车可能强在小平台，弱在复杂转弯 |
| 切割是否过于高效 | 有效接触秒数、脱离代价、目标防切 | 每秒参数高，未必容易保持接触 |
| 控场是否缺少反制 | 预警识别、离圈路线、工具使用 | 命中可能来自出口不足而非数值高 |
| 保护是否导致拖局 | 被救后可行动时长、最终淘汰原因 | 保护一次成功不等于整局难结束 |
| 团队Buff是否左右胜负 | 取得时点、持有损失、实际使用 | 可能由抢点路线而非效果本身决定 |
| 进化是否形成滚雪球 | 品质差距、资源路程、遭遇时点 | 应观察差距形成在哪个阶段 |
| 通行证目标是否合适 | 周有效时间、任务领取、断档 | 不能用完成者平均时长代表所有人 |
| 皮肤是否被使用 | 取得、可用、装备、实际出战 | 领取后可能缺车或找不到装备入口 |

### E.2 更新这份拆解时先做哪件事
