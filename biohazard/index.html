操作说明

A/D 或 ←/→ 移动　　W / Space 跳跃

鼠标 瞄准　　按住左键 射击 / 近战挥砍；投掷物 点按=直接丢 / 长按=蓄力（抛物线变远变直）　　R 换弹

数字键 1-4 切换槽位：1主武器 2副武器 3近战 4投掷（滚轮在武器类别内切换具体枪械）

滚轮 在类别内切换具体武器　　E 交互（弹药箱 / 武器箱 / 关门 / 断桥 / 滑索）

9 / 0 装备地面拾取武器　　G 丢弃拾取武器　　H 能量满变英雄

投掷物：切到投掷物显示抛物线预览；引信类（手雷 / 高爆 / 闪光 / 烟雾 / 烟气 / 治疗 / 冰冻）先按 鼠标右键拔插销，引信立即计时，可控制空爆 / 延迟引爆；拔销不丢会在原地引爆

鼠标右键 开镜：按当前倍率缩放并显示瞄准镜（配件入口已收起，见 config.js 的 配件入口开放）

生化背包：弹药补给点按 E 弹出背包界面，按 1-8 切换（3s 冷却）；B 键全图切换下一号背包（30s 冷却，人类状态可用）

幽灵：Q 释放主动 Buff（紫水晶获得）；死亡清空 Buff、切换关卡保留

触屏：左摇杆移动 · 右侧拖动瞄准并按住开火 · 右下角跳 / 换弹 / 交互 / 技能 · 右上角暂停

开局全员人类：10 秒倒计时内可移动散开，结束后随机 4 名幸存者变异为母体。人类：踩线推进关卡 → 守住防守倒计时 → 越过绿色前线继续，逃到终点撤离获胜；被感染后化为僵尸作战。幽灵：死亡冷却后在当前激活复活点重生，随人类踩线前移形成追尾；关卡切换后强制在新关复活点出生。
