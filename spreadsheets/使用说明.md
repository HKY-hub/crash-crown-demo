# 系统策划 Excel 补充

两份文件均为可编辑的 `.xlsx` 工作簿，不依赖宏或外部文件链接。

## 《撞击王座》系统策划交付表

从“交付索引”开始，按功能ID、车辆ID、能力ID和需求ID回查。表格已设置筛选与冻结表头。

| 内容 | 数量 |
| --- | ---: |
| 系统功能 | 55项 |
| 车辆配置／能力规格 | 各56条 |
| 撞击规则 | 27条 |
| 模式入口规则 | 26条 |
| 界面状态 | 58条 |
| 验收用例 | 98条 |
| 技能原始参数 | 361条 |
| 属性及数值来源 | 1,624条 |
| 策划方案需求索引 | 199条 |

本表配合系统策划双册使用，按系统、功能与需求编号组织配置、状态和验收资料。

“源码定义”“历史记录”“设计要求”和“待核”分别保留。98条验收用例尚未执行；执行时在黄色列填写状态、实际结果、证据／缺陷号和构建日期。不得仅因表中有规则描述就把用例改为通过。

具体数值引用既有配置。体验档属性包含既定天赋与模块条件，不能作为裸车数值直接比较；条件和原始字段在“数值来源”中逐行列出。作品署名按玩法与系统设计归属表述，不将本次制表扩大成代码、美术或具体数值调定的制作经历。

## CS2经济系统配置与预算

适用标准5v5竞技／Premier爆破。按固定提交登记Valve游戏文件镜像，并与官方公告交叉核查；具体链接见“来源登记”。

- **配装预算**：修改阵营、个人现金、物品ID、数量和购买条件，查看采购成本、资金缺口与购买资格。已保留装备设数量0；旧甲补买与已携道具需另行判断。
- **回合预算**：按同一半场逐回合填写支出、击杀收入、个人目标收入、存活与赛果，查看奖励、败局档位和下回合现金。换边另起半场；加时参数单列。
- **现金账本**：按顺序登记收入、单件购买、退款与罚款。购买使用独立实例ID；退款填写原物品及实例，避免重复退还。是否具备购买／退款资格仍由实际游戏状态确认。
- **配置与规则**：45项装备配置（含34把常规枪械）、20项模式参数、结算事件、败局转移、购买退款与12套预算示例。
- **经济验收**：30条手算基准与验证条目。客户端尚未实测的情况在“待验证项”中列出。

浅黄色单元格用于输入，白色计算区保留公式。工作簿已完成公式重算、21项输入与边界检查，以及导出文件核对；未进行Microsoft Excel或WPS原生应用回归，也未把公式检查记为游戏客户端实测。

两份工作簿作为现有网页拆解案、执行策划案的表格附件使用。需要展示某项能力时，先讲清设计目标与规则，再打开相应配置、状态及验收记录。
